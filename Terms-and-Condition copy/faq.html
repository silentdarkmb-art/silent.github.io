Using Codes
Open Roblox and launch the game you have a code for. Inside the game, look for a "Codes", "Twitter", or gift box button — usually found on the main screen, in the settings menu, or in the pause menu. Click it, type or paste the code exactly as shown (codes are case-sensitive), and press Redeem. Your reward should appear in your in-game inventory or currency shortly after.
Promo codes are different from in-game codes. To redeem a promo code, visit roblox.com/redeem, log in to your Roblox account, enter the promo code in the field provided, and click Redeem. Promo codes give free avatar clothing and accessories, not in-game items. You can find current promo codes on our Promo Codes page.

(3) Already redeemed — you may have already used this code on your account. (4) Wrong game — make sure you are in the correct game. (5) Server issue — try rejoining a different server.
