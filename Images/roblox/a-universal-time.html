How to Redeem Codes

  1. Join the Universe Time Studio Roblox group at roblox.com/communities/6556072 — this is required before any code will work.
  2. Launch A Universal Time on Roblox and wait to load into a server.
  3. Press M on your keyboard or tap the two-stripes button in the bottom-left corner to open the main menu.
  4. Click Shop, then go to the Miscellaneous tab. Type or paste your code into the text box — codes are fully case-sensitive — then press Redeem Code to collect your free UCoins, UShards, and Skin Crates.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
🚗 About the Game

About A Universal Time

Developed by Universe Time Studio • Roblox Anime Fighting RPG

A Universal Time is a Roblox anime fighting RPG developed by Universe Time Studio. The game draws characters, abilities, and lore from dozens of series including JoJo's Bizarre Adventure, Dragon Ball Z, Jujutsu Kaisen, Hunter x Hunter, One Piece, and many others. Players explore an open overworld, complete quests, defeat powerful bosses, and fight other players in PvP to earn currency and progress. UCoins and UShards are the primary currencies used for upgrades, ability rerolls, and cosmetic purchases. Skin Crates award random character cosmetics. Codes are released by Universe Time Studio during game updates, milestone events, and as compensation following server issues — and all require Roblox group membership before they can be redeemed.

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Expired Without Warning

AUT codes have no fixed expiry dates but deactivate silently at any point — BEOWULF, HUTAO, GUTSISHERE, KARSWHAT, SORRYFORDELYA, THATSRAD, and LIKEADRAGON all appeared active on Destructoid on March 2 and were confirmed expired on Roblox Den by March 5. If a code returns an invalid response, check BLOXBURST for current status before assuming a typo.

🔡

Case-Sensitive Typo

AUT codes are fully case-sensitive — GAROU is all-caps, SUBTOSTRIFE is mixed-case, and THXFOR700K! includes an exclamation mark. A single wrong character causes the Redeem button to return no reward. Copy and paste directly from BLOXBURST rather than typing manually to eliminate input errors entirely.

🔄

Already Redeemed

Each AUT code is one-time use per account. If the Redeem button returns an already-used response, the UCoins, UShards, or Skin Crates were added to your account at the original redemption time. Check your currency totals and inventory — the rewards were delivered even if you do not recall entering the code previously.

📋

Conflict Between Sources

AUT code status changes rapidly — 7 codes listed as active on Destructoid on March 2 were confirmed expired on Roblox Den by March 5, 2026. BLOXBURST cross-checks Roblox Den (checked daily), Destructoid, and Pocket Tactics before listing. Any code appearing in the expired section of any major tracker is moved to our Expired list immediately, regardless of whether other sources still show it as active.

🔧

Not a Group Member

AUT blocks code redemption entirely unless you are a member of the Universe Time Studio Roblox group at roblox.com/communities/6556072. Unlike most Roblox games where group membership is optional, AUT enforces this as a hard requirement — the Redeem button will not process any code until group membership is confirmed. Join the group first, then re-enter your code.

⚙️

Wrong Menu Location

The AUT code input is not on the main screen. Press M (keyboard) or tap the two-stripes button in the bottom-left corner to open the menu, then navigate to Shop → Miscellaneous tab. The code text box and Redeem Code button are both inside that specific sub-tab — entering a code from any other screen will not work.

⭐ Pro Tips

Beginner Tips for A Universal Time

Grow your spec faster and get maximum value from every AUT code reward
01
Join the Universe Time Studio group before launching AUT

Code redemption in AUT is locked behind group membership — attempting to enter a code before joining the Universe Time Studio group at roblox.com/communities/6556072 will result in no reward regardless of whether the code is valid. Joining the group before your first session ensures every active code can be claimed immediately without needing to restart the game.

02
Redeem all active codes in a single session

AUT codes expire silently with no fixed schedule — seven codes confirmed active on March 2 were expired by March 5, a three-day window. Entering all codes from BLOXBURST's active list in one sitting is the safest approach, as codes available today may not be redeemable by your next login.

03
Spend UShards on spec upgrades before UCoins

UShards are used specifically for spec ability upgrades and are harder to earn through regular gameplay than UCoins. Prioritising UShards from code rewards on ability upgrades before spending UCoins on cosmetics gives your character a meaningful combat edge earlier — especially during version 5.5 where balance changes made upgraded specs noticeably stronger in PvP.

04
Open Skin Crates in bulk rather than one at a time

AUT Skin Crates award random cosmetics — opening multiple crates consecutively in one session gives a broader result set and a higher cumulative chance of landing rarer skins compared to opening single crates across separate sessions. Saving all code-earned crates and opening them together maximises the visual variety of your haul.

05
Complete daily quests immediately after redeeming codes

AUT daily quests award UCoins and other currency on top of whatever code rewards you collected at the start of the session. Completing quests the same day codes are redeemed stacks both income streams — useful for reaching upgrade thresholds faster without relying on additional code drops between sessions.

06
Enable notifications on @kur_Development on X for same-day alerts

AUT codes are released without a predictable schedule — update versions, milestone events, and compensation windows can all trigger a new drop at any time. Following @kur_Development on X with notifications enabled delivers a same-day alert for every new code announcement, reducing the risk of missing a short active window between BLOXBURST check-ins.
