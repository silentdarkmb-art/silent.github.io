🚍 About the Game

About Diesel n Steel

Developed by Diesel n Steel Official Group • Roblox Jeepney Driving Simulator

Diesel n Steel is a Jeepney driving simulator on Roblox developed by the Diesel n Steel Official Group. Set in the province of Bulacan, Philippines, the game recreates the experience of operating a Jeepney — the iconic Philippine public transport vehicle — across a traffic-filled city environment. Players choose from four roles: Driver, Barker, Conductor, or Citizen. As a Driver, passengers are picked up and dropped off at destinations to earn Cash. Cash is used to purchase, customise, and repair Jeepneys. Some codes are hidden as secret codes scattered across the in-game world rather than announced publicly. All codes are case-sensitive and require 500 EXP to unlock the redemption panel, accessed through the Gift Box icon on the left side of the screen.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
🎓

Below 500 EXP Requirement

The Gift Box redemption panel in Diesel n Steel is locked until the player reaches 500 in-game EXP. Attempting to redeem a code before this threshold returns an error stating there is insufficient EXP. This requirement is confirmed by multiple verified sources. The only fix is to earn EXP through regular gameplay — completing passenger runs as the Driver role is the fastest way to accumulate EXP and unlock the code panel.

🔡

Case-Sensitive Input

All Diesel n Steel codes are fully case-sensitive. The active codes include a mix of all-lowercase, all-caps, and mixed-case entries — entering any in the wrong capitalisation produces an invalid code error even when all other characters are correct. Copy and paste directly from BLOXBURST to eliminate case errors entirely. On mobile, autocorrect can silently capitalise the first character of a pasted entry — verify the field after pasting before pressing Redeem!

⏰

Code Has Expired

BLOXBURST cross-checks all major trackers before updating the active list — any code flagged expired or showing a "Check/Unverified" status on any source is moved to expired immediately. The code "watameln" was moved to expired after appearing as "Check" on multiple verified sources despite being listed as active on other sources. If a code from another site does not appear in the active list here, it has been flagged and will not work regardless of what that site shows.

🔄

Already Redeemed

Each Diesel n Steel code can only be claimed once per Roblox account. If the game returns an already-redeemed message, the Cash was added successfully in a previous session and is available in your balance. With eight active codes currently available, keeping a brief note of which ones have already been claimed on your account prevents wasted attempts — especially after returning to the game following a longer break when the active list has changed significantly.

🚫

Extra Space in the Code Field

Copying a code from an external website sometimes includes a hidden space before or after the visible characters. That single extra character causes an invalid code error even when the code itself is perfectly correct. After pasting into the code entry field, click at the very start and end of the input to check for stray spaces before pressing Redeem!. This is most common on mobile devices where clipboard paste behaviour varies between apps and browsers.

🔧

Old Server After Weekend Update

Codes released alongside a new weekend update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour of a Saturday or Sunday patch — exit Diesel n Steel entirely and rejoin to land on a freshly launched server running the current build. This resolves almost all build-related redemption failures immediately and is confirmed as the fix in multiple community reports after recent weekend patches.

⭐ Pro Tips

Beginner Tips for Diesel n Steel

Hit the road smarter and build your Jeepney empire faster
01
Focus on earning 500 EXP first — then redeem all eight active codes immediately

The code redemption panel is locked until 500 EXP is reached. Prioritising passenger runs from the first session rather than exploring or customising reaches this threshold fastest. Once unlocked, redeeming all eight active codes before spending any earned Cash gives the maximum possible free Cash balance to start from — covering at least one early Jeepney purchase without any additional driving required.

02
Stay on your assigned route — off-route driving does not earn passenger fares

Diesel n Steel calculates fares based on passengers transported along the correct route. Driving off-route or making unnecessary detours does not generate Cash from passengers, even if the Jeepney is moving. Staying on the designated route and stopping at marked passenger points consistently earns more Cash per session than attempting shortcuts or exploring, which wastes time that could be spent completing fare-paying trips.

03
Keep your Jeepney repaired — a damaged vehicle earns less and breaks down faster

Vehicle condition in Diesel n Steel degrades with use, and a poorly maintained Jeepney is less efficient at completing trips. Visiting the terminal for repairs before condition drops too low prevents mid-route breakdowns that halt earnings entirely. Using code Cash to fund early repairs rather than waiting until the Jeepney degrades to a critical state keeps earning potential consistent across longer sessions without forced downtime.

04
Explore the game world between routes to hunt for hidden secret codes

multiple verified sources confirms that some Diesel n Steel codes are hidden within the in-game world and are only found through exploration rather than official announcements. Using downtime between passenger runs — such as while waiting for a Jeepney to fill or after completing a repair — to explore less-visited areas of the map is the most productive way to hunt for hidden code objects without sacrificing active earning time on the route.

05
Check back on weekends — new codes typically drop with Saturday and Sunday updates

multiple verified sources confirms that Diesel n Steel updates typically release on weekends. New codes have consistently accompanied major update patches, compensation drops after downtime, and community milestone events. Setting a Saturday reminder to check BLOXBURST or the official Discord codes channel captures new drops before they circulate widely — especially important given that some codes in Diesel n Steel have a short active window tied directly to the update cycle that released them.

06
Try the Barker or Conductor role to understand the full route before switching to Driver

Playing as a Barker or Conductor first gives practical familiarity with the route layout, passenger stop locations, and traffic patterns before taking on the Driver role. Knowing where passengers cluster and which stops see the highest demand translates directly into faster, more efficient routes as a Driver — which compounds Cash earnings across every session. One or two runs in a support role at the start of a new account saves significantly more time than learning the route as a Driver through trial and error.
