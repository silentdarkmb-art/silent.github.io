  💡 Paano gamitin:
  Lagyan ng Code Name + Description bawat row →
  I-toggle ang NEW kung bagong code →
  I-toggle ang EXPIRED kung expired na →
  I-click Generate HTML →
  I-click Copy Active o Copy Expired →
  I-paste sa tamang <div class="codes-list"> sa HTML file mo. Tapos na! 🎉
