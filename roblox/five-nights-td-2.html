✨ About the Game

About Five Nights TD 2

Developed by Hyper TD • FNAF-inspired tower defense sequel on Roblox

Five Nights TD 2 is the follow-up to the original FNTD game, developed by Hyper TD. It is a tower defense game set in the Five Nights at Freddy's universe where players place iconic animatronic characters as units to defend against waves of enemies. Unlike the original game, the sequel introduces a reworked shiny booster system — shinies now only affect attack range rather than all booster stats, making unit composition and positioning more strategically important. The game currently runs in Season 3, which introduced new units, a revamped clan system, new seasonal events, and the updated summoning economy where Coins, Souls, and Tokens each serve distinct roles in building and upgrading your defense roster.

Coins

Coins are the primary summon currency in Five Nights TD 2, used to pull from the standard summon pool for animatronic units. Update codes consistently award 5,000 Coins each — and with over 20 active update codes currently available, redeeming all of them delivers more than 100,000 Coins combined. That amount covers dozens of standard summons, providing a significant unit roster advantage over players who enter without redeeming codes first. Coins stack directly with match earnings and can be spent immediately on summons after redemption.

Souls

Souls are a premium currency in Five Nights TD 2 used to access higher-rarity summon pools that have a better chance of producing legendary-tier animatronic units. Each Soul is significantly more valuable per pull than a standard Coin summon. Active codes that award Souls provide 10 per redemption — and with multiple Soul-awarding codes currently active, the combined Soul income from code redemption alone is enough to execute several premium summons without spending any earned in-game currency on the same pool.

Presents

Presents are seasonal reward bundles that contain randomized drops from within a specific seasonal loot table — including exclusive units, upgrade materials, and currencies that are not available through standard shop or summon purchases. OG Presents and Season 2 Presents from older active codes provide loot tied to previous seasonal events but still contain valuable items usable in the current Season 3 meta. Season 3 Presents from the most recent update codes contain Season 3-specific rewards including new event-tied units.

Tokens

Tokens are a third distinct currency used for event-limited unit purchases and specific seasonal shop transactions that are not accessible through Coins or Souls. The UPDATE10 code awards 5,000 Tokens alongside two OG Presents — making it one of the most comprehensive single-code drops in the game's history. Tokens are harder to earn through regular match play than Coins, making code-granted Token income proportionally more impactful per unit of currency received compared to equivalent Coin drops from the same code pool.

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Expired After a New Update

Five Nights TD 2 codes expire alongside or shortly after new updates are released. Only 6 codes have expired so far out of the game's large historical code list — the developer has been unusually generous in keeping older codes active — but the 6 confirmed expired codes demonstrate that expiry can happen without advance notice. BLOXBURST moves any code confirmed expired on a verified source to the expired section immediately. The active list here is verified as of March 20, 2026 using sources that checked the codes on the same date.

🔡

Wrong Case — Codes Are All Uppercase

All Five Nights TD 2 codes use uppercase formatting — entering any code in lowercase or mixed case triggers an invalid code error even if every other character is correct. Some codes also contain numbers and special characters like exclamation marks that must be included exactly. Copy and paste directly from BLOXBURST using the Copy button on each card to avoid this entirely. Check for any accidental spaces before or after the pasted code text in the entry box before pressing the Enter button.

🔁

Already Redeemed

Each code in Five Nights TD 2 is single-use per Roblox account. With 60 active codes available, tracking which have been redeemed across multiple sessions requires attention — it is easy to lose track particularly for older update codes that have been available since the game's earlier seasons. A "code already redeemed" message should not be confused with an expired or invalid code error, as the rewards were already delivered to your account in a previous session.

🔧

Server Running Old Build

Codes released with a new numbered update can fail on servers still running the previous build — particularly in the first hour after Update 20 or any future update goes live. If a freshly confirmed code does not register on first attempt, exit Five Nights TD 2 completely and rejoin to land on a current-build server. This resolves build-mismatch errors quickly and is most relevant immediately after each new numbered update while servers gradually transition to the updated version across all active instances.

⚙️

Can't Find the Code Entry Field

The code entry field in Five Nights TD 2 is inside the Settings menu, accessed through the gear icon in the top-right corner of the screen. The code box is located at the bottom of the Settings panel — it is not visible without scrolling to the bottom if the panel is long. Players who open Settings and see the general options at the top without scrolling down will not find the entry box. Scrolling to the very bottom of the Settings panel reveals the Enter Code text box next to the Twitter logo icon.

📋

Source Conflict — Code Moved to Expired

⭐ Pro Tips

Beginner Tips for Five Nights TD 2

Summon stronger units, clear harder waves, and dominate every night
01
Redeem all 60 active codes before your first summon — over 100,000 Coins available

The combined Coin income from all active update codes alone exceeds 100,000 Coins before factoring in Souls, Tokens, and Presents. Redeeming the complete active list before making any summon purchases means your entire starting budget is available for a single informed spending session. Players who summon before redeeming codes spend a portion of their budget on pulls that code currency would have covered for free, producing a smaller and lower-rarity starting roster than the available free currency would have enabled.

02
Spend Souls on premium summons, not standard pulls

Souls access a higher-rarity summon pool than Coins — using Souls on standard Coin-tier pulls wastes the premium value of the currency entirely. Save all Soul income from codes specifically for the premium summon option, where the improved rarity distribution produces a significantly better average return per Soul spent compared to substituting Souls for Coins in a standard pull session. The Soul codes in the active list collectively provide enough for several premium pulls with no additional grinding.

03
Prioritize unit placement near choke points, not spread evenly across the map

Five Nights TD 2 enemies follow fixed pathing routes — units placed at natural choke points where paths narrow or converge deal damage to every enemy that passes rather than only those within direct range of isolated placements. Concentrating your strongest units at two or three key choke points consistently outperforms an even distribution across the full map, because grouped high-damage units share a target pool that maximizes their damage output per wave rather than each unit engaging a separate fraction of the enemy count.

04
Upgrade your highest-rarity units before buying new ones

Upgrading a high-rarity unit increases its damage and ability effectiveness at a lower total resource cost than the equivalent power gain from pulling another unit of the same rarity and not upgrading either. Once your roster includes at least one or two legendary-tier units, reinvesting upgrade resources into those units rather than spending on additional summons produces faster overall roster performance growth. Low-rarity units become redundant quickly in higher-wave content, making upgrade investment in elite units the better long-term resource allocation strategy.

05
Join a clan to unlock additional quest rewards

Five Nights TD 2 includes a clan system where members complete shared objectives to earn bonus Coins, Souls, and occasionally exclusive unit access. Active clans with consistent members complete clan quests faster, producing a higher per-session currency income beyond what solo play generates. The CLANQUESTS code was a previous milestone reward tied to the clan system — monitoring the Discord for future clan milestone codes is easier when you are already an active clan member visible in the relevant community announcements.

06
Redeem each new update code the same day it drops

Although Five Nights TD 2 has one of the most generous active code records in Roblox tower defense — keeping most codes active across multiple seasons — the 6 currently expired codes demonstrate that expiry can happen without warning. Treating each new numbered update code as time-sensitive and redeeming on the same day it is confirmed active eliminates the risk entirely. The Discord codes channel is the fastest notification source, and BLOXBURST is the most reliable external reference for confirming active status before entering a code in-game.
