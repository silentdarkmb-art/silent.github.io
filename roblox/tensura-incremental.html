About Tensura Incremental

Developed by Vaelora • Roblox That Time I Got Reincarnated as a Slime Incremental RPG

Tensura Incremental is a That Time I Got Reincarnated as a Slime-inspired incremental RPG developed by Vaelora on Roblox. Players begin as a simple monster and grow stronger by consuming enemies — absorbing their abilities and evolving through a massive evolution tree that unlocks hundreds of unique skills and powers. Race, Skill, and Spirit assignments shape your character's identity and combat capability, with each combination enabling a distinct playstyle suited to different content. What Do Codes Give You?

Free Race Rerolls, Skill Rolls, and Spirit Rolls to build the perfect monster character faster
🔄

Race & Skill Rerolls

Race Rerolls and Skill Rolls are the core code rewards in Tensura Incremental, directly increasing your attempts at obtaining rare Race assignments and high-tier Skill abilities without spending in-game resources. Race determines your fundamental stat profile and passive bonuses, while Skills provide the active combat abilities that define your playstyle in dungeon and enemy encounters. Most active codes award both simultaneously — maximising the number of attempts at a strong combined build from the earliest sessions.

Core Build Resources
👻

Spirit Rolls

Spirit Rolls award elemental spirit assignments that augment your monster's abilities with elemental properties — fire, water, wind, earth, and rarer spirit types each adding unique passive and active bonuses on top of your Race and Skill loadout. Spirit codes are slightly less common than Race and Skill codes but provide a meaningful third layer of build customisation that becomes increasingly important in higher-difficulty dungeon content where elemental matchups affect combat outcomes.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Case-Sensitive Input

All Tensura Incremental codes are fully case-sensitive. Entering any character incorrectly — including capitalisation — produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Redeem.

⏰

Code Has Expired

Tensura Incremental codes can expire without advance notice. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code does not appear in the active list here, it has been flagged and will not work.

👥

Not in the Roblox Group

Tensura Incremental requires all players to be members of the Vaelora Roblox Group before any code can be redeemed. Attempting to redeem without group membership will result in an immediate failure regardless of whether the code is valid. Join the group first, then relaunch the game and attempt the redemption again — this resolves the vast majority of first-time redemption failures.

🔧

Old Server After Update

Codes released with a new Tensura Incremental update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately.

🚫

Extra Space in the Code Field

Copying a code can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. After pasting, click at the very start and end of the code field to check for extra spaces before pressing Redeem. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

🔄

Already Redeemed

Each Tensura Incremental code is single-use per Roblox account. If the game returns an already-redeemed message, the Rerolls or Rolls were added to your account in a previous session. Players returning after a gap may have claimed codes they no longer remember redeeming — checking the active list against memory before attempting codes prevents repeated failed attempts.

Beginner Tips for Tensura Incremental

Evolve faster, build stronger, and conquer dungeons from day one
01
Join the Vaelora Roblox Group before anything else — it unlocks all 15 active codes

Before launching the game for the first time, join the Vaelora Roblox Group. Group membership is required for code redemption — no code will work without it. Joining takes seconds and immediately unlocks access to all 15 active codes, providing Race Rerolls, Skill Rolls, and Spirit Rolls across three simultaneous reward tracks before your first enemy encounter.

02
Redeem all codes before your first roll — stack the free resources first

After joining the group, redeem all 15 active codes before spending any in-game resources on rolls. The combined Race Rerolls, Skill Rolls, and Spirit Rolls from all current codes give you a far broader starting pool than beginning with only base resources. Starting your first roll session with this stockpile maximises the chance of landing a rare Race and strong Skill combination in the opening session.

03
Prioritise Race first — it sets your stat foundation for every other build decision

Race determines your base stat distribution and passive bonus profile that underpins every Skill and Spirit combination you use. Locking a strong Race before investing Skill and Spirit Rolls ensures those resources are spent building on a solid foundation rather than compensating for a weak Race's stat gaps. Use Race Rerolls from codes to find a rare or epic-tier Race before committing any Skill or Spirit resources.

04
Match your Spirit element to your Skill abilities for maximum damage output

Spirit elemental assignments provide bonus damage multipliers that stack on top of Skill ability damage when the Spirit element and Skill type are aligned. A fire Spirit paired with fire-based Skills compounds the damage of each ability significantly compared to a mismatched elemental pairing. When using Spirit Rolls from codes, target Spirit elements that match the primary damage type of your current best Skill — the synergy bonus is consistently larger than the raw stat bonus from any mismatched Spirit.

05
Push into Dungeons as soon as they unlock — they provide the best reroll resource drops

Dungeons in Tensura Incremental drop Race Reroll and Skill Roll resources at rates significantly higher than standard enemy encounters. The DUNGEONS code was released specifically to celebrate this content — signalling that Vaelora considers dungeon access a core progression milestone. Prioritising the story and evolution content required to unlock Dungeons accelerates your reroll resource generation far beyond what grinding on standard enemies can achieve.

06
Watch all three milestone counters — visits, likes, and members each trigger new codes

Tensura Incremental releases codes across three simultaneous milestone tracks — the 40K, 65K, 100K, and 150K visit codes, the 500, 800, 1K, and 2K like codes, and the 6K, 10K, and 18K member codes are all active evidence of this pattern. Watching the game page visit counter, the like count, and the Vaelora group member count simultaneously means there are always multiple upcoming code drops to anticipate — the next milestones across all three tracks are all within reach as the game continues to grow.
