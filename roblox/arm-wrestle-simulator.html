🚗 About the Game

About Arm Wrestle Simulator

Developed by Kubo Games • Roblox Strength Clicker & PvP Simulator

Arm Wrestle Simulator is a Roblox strength clicker developed by Kubo Games. Players train three core stats — Bicep Power, Hand Strength, and Knuckle Strength — using equipment and idle mechanics, then compete in direct arm wrestling matches to earn wins. Wins fund rebirths, which permanently multiply all stat gains across every discipline. Pets collected from eggs add passive stat multipliers, and new gyms unlock progressively harder opponents as your power scales. Codes drop every Saturday alongside weekly updates and are also released for seasonal events, chaos arc milestones, and delay compensation. They award Stat Boosts, timed 3x Strength Multipliers, and special event items.

💪 Gameplay

Train Bicep Power, Hand Strength, and Knuckle Strength simultaneously using gym equipment. Challenge a sequence of opponents in arm wrestling matches — each defeated opponent awards wins used to purchase rebirths. Every rebirth multiplies future stat gains permanently, making early rebirths the most impactful investment available to new players.

🎁 Code Drops

Kubo Games releases codes every Saturday alongside the weekly game update. Additional codes appear during chaos and seasonal arc milestones — the Atomic Island update produced both atomicishere and chaoticbosses simultaneously. Codes are announced on the official Kubo Discord server and via developer @axelmakes on X. Some codes include explicit expiry dates — chaoticbosses is marked as expiring March 7, 2026.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Expiry-Dated Code Has Closed

AWS codes with an explicit expiry date — such as chaoticbosses expiring March 7, 2026 — deactivate on the stated calendar date regardless of any other update activity. If the code returns INVALID after the announced date, the window is permanently closed and cannot be reopened by rejoining or switching servers.

🔡

Case-Insensitive — But Spelling Matters

Unlike many Roblox games, AWS codes are fully case-insensitive — capitalisation does not affect redemption. However, spelling must still be exact. A single wrong letter, missing character, or extra space will cause the Verify button to reject the entry. Copy and paste directly from BLOXBURST to avoid any input error.

🔄

Already Redeemed

Each AWS code is one-time use per account. If the Verify button returns an already-used message, the boost and stats were applied to your account at the time of the original redemption. Permanent stat gains from codes like chaoticbosses are kept permanently even after the timed boost portion expires.

📋

Conflict Between Sources

AWS codes frequently appear on one tracker while already expired on another — woohoomailbox, toyfactory, and christmaspart2 were listed as active on PCGamesN but confirmed expired on Try Hard Guides on the same date. BLOXBURST cross-checks both sources before listing — any code that appears expired on either major tracker is moved directly to our Expired section.

🔧

Server Not Updated

New AWS codes released alongside the Saturday weekly update can fail on servers still running the previous build. Closing Arm Wrestle Simulator completely and reopening it places you on a fresh server with the current weekly patch — this resolves most INVALID responses on codes confirmed active on BLOXBURST immediately after a Saturday drop.

⚙️

Wrong Button Location

The code input in AWS is not in the main game screen. Click the Store button on the left side of the screen first, then look for the Codes button in the bottom-right corner of the Store window — not the main shop tabs. The Enter Code text box and green Verify button are inside that specific sub-menu.
