🎲 About the Game

About RNG Incremental

Developed by Incremental games and stuff • Roblox RNG Incremental Progression Game

RNG Incremental is a dice-rolling incremental progression game developed by Incremental games and stuff on Roblox. Players roll the dice to grow their numbers, ascend to gain power multipliers, and unlock new areas like the Aether Island as they push further into the game's progression layers. Scrolls are used to upgrade the Soul Fragment skill tree — a branching system that provides passive bonuses across every aspect of the game's incremental loop. Potions provide temporary boosts that accelerate specific phases of progression, and collecting them across multiple potion types simultaneously maximises their combined benefit. Scrolls and Potions from codes give new players an immediate head start that bypasses the slowest early phases of the ascension and skill tree grind.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Case-Sensitive Input

All RNG Incremental codes are fully case-sensitive. Entering any character incorrectly — including capitalisation — produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Redeem.

⏰

Code Has Expired

RNG Incremental codes can expire without advance notice. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code does not appear in the active list here, it has been flagged and will not work.

🔄

Already Redeemed

Each RNG Incremental code is single-use per Roblox account. If the game returns an already-redeemed message, the Scrolls or Potions were added to your account in a previous session. Players returning after a gap may have claimed codes they no longer remember redeeming — checking the active list against memory before attempting codes prevents repeated failed attempts.

🔧

Old Server After Update

Codes released with a new RNG Incremental update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately.

🚫

Extra Space in the Code Field

Copying a code can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. After pasting, click at the very start and end of the code field to check for extra spaces before pressing Redeem. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

🛒

Wrong Menu Location

RNG Incremental codes can only be redeemed through the Shopping Cart button on the left side of the screen — scroll to the bottom of the Shop window to find the code input box. Players who look for a code field at the top of the Shop or elsewhere in the UI without scrolling to the bottom will not find it. The input box is specifically at the very bottom of the Shop panel.

⭐ Pro Tips

Beginner Tips for RNG Incremental

Roll bigger numbers, ascend faster, and unlock Aether Island sooner from day one
01
Redeem all codes before spending any Scrolls — invest the 2,500 from AETHER into your first skill tree nodes immediately

Before spending any earned Scrolls, redeem all active codes — especially AETHER which awards 2,500 Scrolls directly. Investing this combined pool into the first skill tree nodes immediately provides passive bonuses that affect every roll and ascension cycle from this point forward. Starting the skill tree with code Scrolls rather than ground ones compresses the earliest and most grind-intensive phase of the progression by several sessions.

02
Use all potions from 20KVISITS during the same active session — stacking all types simultaneously maximises their combined effect

The one-of-every-potion reward from 20KVISITS covers every progression stat category simultaneously. Activating all potion types at the start of the same active grinding session stacks their individual temporary boosts into a compounding window that affects rolls, ascension speed, and Aether Island productivity all at once. Spreading potion activations across different sessions reduces the compounding benefit and prevents the different boost types from amplifying each other.

03
Prioritise roll multiplier nodes in the skill tree before ascension speed nodes

Roll multiplier nodes increase the base number generated per roll — which compounds directly into every ascension cycle's starting value. Ascension speed nodes reduce the time between resets but provide less total value if the numbers generated per roll are still low. Investing early Scrolls into roll multiplier nodes first establishes a stronger numeric base that makes ascension speed nodes significantly more impactful when added on top.

04
Ascend as soon as the multiplier gain outweighs the reset cost — don't wait for a round number

Ascension in RNG Incremental provides a permanent multiplier on all future run values. The optimal ascension timing arrives earlier than most new players expect — the point where the multiplier gain from ascending now produces faster cumulative progress than continuing to grind the current run. Waiting for a psychologically satisfying round number before ascending consistently delays the compound multiplier that makes the game's later progression dramatically faster.

05
Unlock Aether Island as early as possible — it adds a second progression income stream

Aether Island introduces a second layer of resource generation that compounds on top of the main ascension loop rather than replacing it. Reaching the unlock threshold for Aether Island as quickly as possible — prioritising the relevant skill tree nodes and ascension milestones that gate its access — adds a continuous passive resource stream that accelerates both the main loop and the island's own progression simultaneously from the moment it unlocks.

06
Watch the visit counter and Discord for the next code — the naming pattern makes drops predictable

RNG Incremental's code release pattern is directly tied to visit milestones and update names — 20KVISITS and AETHER are both exact reflections of the events that triggered them. With the game at 20K visits, the next milestone code at 50K or 100K visits is already forming, and any future content update will carry its own code. Watching the visit counter on the Roblox game page and the Discord announcements channel when it approaches round numbers gives advance notice before each new drop.
