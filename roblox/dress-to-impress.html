How to Redeem Codes

  1. Launch Dress To Impress on Roblox and wait to enter the dressing room.
  2. Click the pink handbag icon labeled CODE on the left side of the screen to open the Codes window.
  3. Type or paste your code exactly into the Enter code here text box — all DTI codes must be entered in ALL CAPS and are case-sensitive.
  4. Press the pink Redeem button to claim your free outfit item or accessory instantly.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
👗 About the Game

About Dress To Impress

Developed by Dress To Impress Group • Roblox Fashion Competition

Dress To Impress is a Roblox fashion competition experience developed by Dress To Impress Group. Each round, players are given a theme and a short timer to assemble the best possible outfit from their wardrobe, then walk the runway while other players vote on each look. Votes are converted into stars, which determine your leaderboard ranking and progress through model tiers. The game has grown to over 9 billion visits, making it one of Roblox's most popular fashion titles. All codes are ALL-CAPS and case-sensitive.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
🔡

Code Not In ALL CAPS

Every single Dress To Impress code must be entered in full uppercase — entering lny, Liondancer, or cupidscloud instead of the correct ALL-CAPS format will return "Invalid Code" even if the code is currently active and working on your account. DTI is one of the few Roblox games where this rule applies to every code without exception. Copy and paste each code directly from BLOXBURST to guarantee correct capitalisation rather than typing manually from memory.

0️⃣

Zero vs. Letter O in Codes

Several Dress To Impress codes substitute the number zero (0) for the letter O as part of the code format — CH00P1E_1S_B4CK uses two zeros in "CH00P1E", 1CON1CF4TMA has no zeros but uses the number 1 for the letter I, and S3M_0W3N_Y4Y has a zero in "0WEN". Typing the letter O where a zero is required causes the code to fail. When in doubt, copy and paste directly from the code card above — the exact character is preserved automatically, removing any guesswork about zeros versus O's in the code string.

⏰

Seasonal Code Expired

Several DTI codes are tied to limited-time events and expire when the event window ends rather than staying active permanently. The expired codes in the section above — including ELPHABA, GLINDA (Wicked event), 2YEARS, 2GETHER, and RDC2025 — are examples of codes that were valid during specific periods and then expired. If a code from any external source returns "Expired Code" in DTI, it is no longer redeemable. BLOXBURST moves conflicting codes to the expired section immediately so you can skip attempting them.

🔁

Already Redeemed

Each Dress To Impress code is single-use per Roblox account. If the game shows a message indicating the code was already redeemed, the item was successfully added to your wardrobe in a previous session and cannot be claimed again. With 30 active codes currently listed, cross-check your wardrobe or redeem history before assuming a code is broken — especially if you have used BLOXBURST lists before and may have already claimed some of the longer-standing codes like KREEK, ELLA, or the LANA-series codes.

🔧

Wrong Menu — Handbag Icon vs. Shop

The code redemption button in Dress To Impress is the pink handbag icon labeled CODE on the left side of the dressing room screen — it is separate from other buttons in the interface. Clicking the wrong icon will open a different menu without a code entry field. If you cannot find the code input box, look specifically for the handbag icon on the far left of the screen, click it, and the Codes window with a text entry field at the top will open. The previously redeemed items list also appears below the entry box for reference.

🌐

Outdated Server After an Update

If a newly released Dress To Impress code fails on first attempt — especially on the same day as an update announcement — the server you are on may still be running the previous build. New codes released alongside a patch sometimes require the updated server version to register. Exiting Dress To Impress entirely and rejoining places you in a server running the current version in most cases, which resolves the issue. This is most common in the first 30–60 minutes after a major update, when servers are being updated asynchronously across the player pool.

⭐ Pro Tips

Beginner Tips for Dress To Impress

Win more rounds, earn more stars, and build a stronger wardrobe faster
01
Redeem all 30 active codes before your first competitive round

All 30 active codes award clothing items or accessories directly to your wardrobe — there are no prerequisites and no purchase required. Redeeming everything before entering competitive play gives you a significantly wider outfit selection from the start, including full sets like the LIONDANCER set, LANA multi-piece bundle, and CH00P1E_1S_B4CK three-piece collection. A larger starting wardrobe means more theme-matching options when the round timer starts, which directly improves your chances of assembling a vote-winning look without running out of time.

02
Copy codes directly — never type them manually

Dress To Impress codes use a mix of letters, numbers, and underscores where specific digits substitute for letters — zeros replace O in CH00P1E_1S_B4CK and S3M_0W3N_Y4Y, and the number 3 replaces E in several creator codes. Typing from memory introduces substitution errors that cause even valid codes to fail. Copying directly from the BLOXBURST code card preserves the exact character string every time — use the Copy button on each card rather than reading and retyping.

03
Prioritize seasonal codes immediately — they can expire with their event

The currently active seasonal codes — LNY, LIONDANCER, BHM26, and CUPIDSCLOUD — are tied to the Lunar New Year and Valentine's Day update windows. Past seasonal codes like ELPHABA and GLINDA (Wicked event) expired when their event ended. Claiming the four newest codes at the top of the list before any others ensures you secure the items most at risk of expiring, before the associated events conclude and the codes become permanently unavailable.

04
Build themed outfit bundles from your code rewards in advance

Before each session, spend a few minutes in the dressing room building and saving outfit presets using your code-awarded items. Group items by theme — fantasy, casual, seasonal, Y2K, and so on — so that when a matching theme appears on the runway, you already have a pre-built outfit ready rather than assembling from scratch under the timer. Code items like M3RM4ID (Mermaid Tail + Shell Top), S3M_0W3N_Y4Y (Staff/Scythe/Axe), and the LANA series lend themselves to specific theme categories, making them particularly useful for fast outfit assembly in the right round.

05
Focus accessories on completing an outfit, not replacing it

Code accessories — including the Pearl Purse from TEKKYOOZ, Bow + Purse from D1ORST4R, Lashes + Necklace from SUBM15CY, Hair Bow from LANABOW, and Beanie from KREEK — are most effective when they complement an already strong thematic outfit rather than being added without coordination. Experienced DTI players vote for looks where every element feels intentional — an accessory that clearly belongs to the outfit theme earns more votes than a generic one layered onto an outfit it doesn't match.

06
Use the voting round to study what wins — not just to earn stars

The runway voting phase gives you a direct view of what other players are wearing and how many votes each look earns. Rather than only watching your own votes accumulate, observe the top-ranked outfits to identify which accessory combinations, color choices, and structural approaches are scoring highest on that particular theme. This makes future rounds significantly easier — you are learning what the DTI player base responds to in real time rather than guessing based on your own preferences alone.
