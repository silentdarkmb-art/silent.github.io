How to Redeem Codes

  1. Launch GHOUL://RE on Roblox and load into the game.
  2. Click the Menu button at the top left of the screen.
  3. Press the </> (Codes) icon at the top right of the Menu window.

👁️ About the Game

About GHOUL://RE

Developed by Ghoul RE • Roblox Tokyo Ghoul-Inspired Action RPG

GHOUL://RE is a Tokyo Ghoul-inspired open-world action RPG developed by Ghoul RE on Roblox. Players choose to play as a Ghoul or a CCG Investigator — each faction with its own distinct combat style, skill tree, and progression path. Ghouls wield Kagune in battle while CCG Investigators deploy Quinque to hunt them down. Ghoul Points earned from codes are used to reroll character traits and upgrade abilities, accelerating progression through the early grind. Note that Ghoul Points have a cap of 1,500 — redeeming beyond the cap will not add additional points.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Case-Sensitive Input

All GHOUL://RE codes are fully case-sensitive and many contain mixed capitalisation, exclamation marks, and punctuation characters. Entering any character incorrectly produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Confirm.

📊

Ghoul Points Cap Reached

GHOUL://RE enforces a hard cap of 1,500 Ghoul Points per account. Attempting to redeem a code while already at the cap will either fail or result in GP being lost above the ceiling. Before redeeming any code, check your current GP balance and spend points on trait rerolls to bring it below the cap. This is the most common missed step for returning players who have accumulated points across multiple sessions.

⏰

Code Has Expired

GHOUL://RE codes can expire without advance notice — particularly compensation codes released after outages, which carry very short active windows. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code does not appear in the active list here, it has been flagged and will not work.

🔄

Already Redeemed

Each GHOUL://RE code is single-use per Roblox account. If the game returns an already-redeemed message, the Ghoul Points were added in a previous session. With a long history of update and compensation codes stretching back through 2024, players returning after a gap may have claimed codes they no longer remember — checking the active list against memory before attempting prevents repeated failed attempts.

🔧

Old Server After Update

Codes released alongside a new GHOUL://RE update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately.

🚫

Extra Space in the Code Field

Copying a code can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. After pasting, click at the very start and end of the Insert Code field to check for extra spaces before pressing Confirm. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

⭐ Pro Tips

Beginner Tips for GHOUL://RE

Master your faction, stack Ghoul Points wisely, and survive Tokyo
01
Redeem all active codes first — then spend GP before the cap blocks new ones

Before entering combat, redeem every active code to collect free Ghoul Points. Then immediately spend those GP on trait rerolls before accumulating more — the 1,500 GP cap means holding points without spending them will cause future code rewards to be lost above the ceiling. Redeem, spend, repeat every session.

02
Pick your faction carefully — switching resets significant progress

Choosing between Ghoul and CCG Investigator is the most impactful early decision in GHOUL://RE. Ghouls use Kagune in close-range combat while CCG Investigators deploy Quinque from range. Both factions have distinct skill trees that take many sessions to develop — committing to one faction and advancing its tree consistently is far more efficient than switching mid-progression.

03
Learn your Kagune or Quinque moveset on lower-level enemies before PvP

Each Kagune and Quinque has a distinct set of moves with different ranges, cooldowns, and damage profiles. Practising the full moveset against weaker NPCs before entering player fights builds the muscle memory needed to chain abilities effectively under pressure. Entering PvP without knowing your moveset results in avoidable deaths that slow level progression.

04
Use GP on trait rerolls strategically — target combat-boosting traits first

Ghoul Points are spent on trait rerolls that randomise base stat bonuses. Not all traits are equal — combat-boosting traits that increase damage output or defensive stats provide compounding value across every future fight, while utility traits offer situational benefits. Spending GP on combat traits early and holding utility rerolls for later maximises the return on every point redeemed from codes.

05
Check Discord after every update — compensation codes drop without warning

Ghoul RE releases compensation codes after server outages, game-breaking bugs, and delayed updates — these codes carry the shortest active windows of any release type, sometimes expiring within 24 to 48 hours. Checking the Discord announcements channel after any unexpected downtime is the only reliable way to catch compensation codes before they disappear.

06
Follow the bi-weekly update schedule to plan your GP spending

GHOUL://RE operates on a consistent bi-weekly update cycle, with each patch bringing new content, balance changes, and a fresh code at the end of the update log. Planning GP spending around the update schedule — spending points before a patch and redeeming the new code immediately after — ensures the cap never blocks incoming rewards from new drops.
