🍔 About the Game

About Get Fat to Splash

Developed by Hit Everything Gaming • Roblox Eating and Splash Simulator

Get Fat to Splash is a hilarious eating and splash simulator developed by Hit Everything Gaming on Roblox. Players eat junk food to grow their character as large as possible, then dive into the pool to create the biggest splash they can — with splash size determining the Cash earned per dive. Cash is reinvested into better food to grow even faster, creating a satisfying loop of eating, growing, and splashing. Pets with high Fat multipliers accelerate growth further, and leaderboards reward the heaviest and highest-earning players each session. Fat Potions from codes provide an immediate growth boost that skips the early grind entirely.

🍔 Gameplay Loop

Eat food to increase your character's size — the larger the belly, the bigger the splash and the more Cash earned per dive. Cash funds better food that accelerates growth further, compounding across each session. Pets with high Fat multipliers provide a passive size boost on top of active eating, making Pet quality a key progression driver. Hitting the pool repeatedly and reinvesting every Cash payout into the best available food is the fastest path to climbing the splash leaderboard without spending Robux.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Case-Sensitive Input

All Get Fat to Splash codes are fully case-sensitive. Entering any character incorrectly — including capitalisation — produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Submit.

⏰

Code Has Expired

Get Fat to Splash codes can expire without advance notice. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code does not appear in the active list here, it has been flagged and will not work.

🔄

Already Redeemed

Each Get Fat to Splash code is single-use per Roblox account. If the game returns an already-redeemed message, the Fat Potion or Cash was added to your account in a previous session. Players returning after a gap may have claimed codes they no longer remember redeeming — checking the active list against memory before attempting codes prevents repeated failed attempts.

🔧

Old Server After Update

Codes released with a new Get Fat to Splash update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately.

🚫

Extra Space in the Code Field

Copying a code can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. After pasting, click at the very start and end of the code field to check for extra spaces before pressing Submit. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

🛍️

Wrong Menu Location

Get Fat to Splash codes can only be redeemed through the Shop button on the left side of the screen — scroll to the bottom of the Shop window or press the COD button to find the code input field. Players who look for the code box outside of the Shop menu will not find it. If the COD button is not visible, scroll down within the Shop window until the text box appears at the bottom.

⭐ Pro Tips

Beginner Tips for Get Fat to Splash

Grow bigger, splash harder, and stack Cash faster from day one
01
Redeem all active codes before your first splash — Fat Potions expire

Before eating a single piece of food, redeem all active codes first. Fat Potions from codes provide an immediate size boost that stacks directly on top of your starting state — meaning the first splash after redeeming codes is significantly larger and more profitable than it would be without them.

02
Use Fat Potions right before hitting the pool — not between eating sessions

Fat Potions provide a temporary size boost that compounds with your current belly size. Activating a potion when you are already at maximum eating capacity — right before the pool dive — maximises the splash value of the boost. Using a potion too early and then continuing to eat resets the benefit timing and reduces the Cash return per potion used.

03
Always reinvest Cash into the best food available immediately

Holding Cash without spending it on better food slows progression significantly — each food tier directly increases the rate of size gain per session. Reinvesting every Cash payout into the highest-tier food available keeps the growth curve steep and ensures the next splash is always larger than the last.

04
Prioritise hatching Pets with high Fat multipliers early

Pets provide a passive Fat multiplier that stacks on top of all active food consumption — making a high-multiplier pet worth significantly more long-term than a single food upgrade. Allocating a portion of early Cash toward Pet hatching rather than exclusively reinvesting in food accelerates the growth rate across all future sessions.

05
Check the game description on Roblox for codes before each session

Hit Everything Gaming regularly posts the latest active code directly in the Get Fat to Splash game description. Checking it takes seconds and is the fastest way to confirm whether a new code has dropped since the last visit — without needing to open Discord or search externally. A new code in the description means free Fat Potions waiting to be claimed.

06
Play during active sessions to climb the leaderboard for bonus rewards

Get Fat to Splash leaderboards reward the heaviest and highest-earning players each session with bonus Cash payouts. Playing during peak hours when other players are active increases leaderboard competition — but also means the top positions are worth more. Combining a full Fat Potion redeem with a peak-hour session is the optimal window for a high leaderboard finish.
