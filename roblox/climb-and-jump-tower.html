How to Redeem Codes

  1. Launch Climb and Jump Tower on Roblox and wait for the game to fully load.
  2. Click the Codes button in the top-right corner of the screen.
  3. Type or paste your code exactly into the Enter Code field — codes are case-sensitive.
  4. Click the green USE button to instantly collect your free Souvenir Box or reward.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
🏙️ About the Game

About Climb and Jump Tower

Developed by Climbing World • Roblox Landmark Climbing Game

Climb and Jump Tower is a Roblox climbing game developed by Climbing World. Players scale recreations of iconic real-world landmarks — including the Eiffel Tower, Statue of Liberty, Leaning Tower of Pisa, and the Pyramids — racing to the top while collecting Coins along the way. Seasonal worlds and event updates expand the map regularly, with the current Season 4 New World adding fresh structures to conquer. Souvenir Boxes earned from codes contain themed collectibles tied to each landmark zone. Codes are announced in the game's patch notes and official Discord, and all codes are case-sensitive.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
🔡

Case-Sensitive Typo

All Climb and Jump Tower codes use all-capital letters — entering even one character in lowercase will cause the USE button to reject the entry. Copy and paste directly from BLOXBURST rather than typing manually, and check for any accidental spaces before or after the code text, which can also trigger a failed redemption on an otherwise valid code.

⏰

Code Has Expired

Climb and Jump Tower codes expire without advance notice — often when the next update goes live and replaces the previous patch's code. Attempting an expired code returns an error even if it still appears listed as active on some outdated trackers. Always use the verified active list at the top of this page for the most current status before attempting a redemption.

🔁

Already Redeemed

Each code in Climb and Jump Tower is one-time use per Roblox account. If the game returns a message indicating the code has already been used, the Souvenir Box or reward was successfully collected on your account at a prior session — the code worked correctly, it simply cannot be claimed twice on the same profile.

📋

Conflict Between Sources

Some codes appear active on one tracker but expired on another, particularly codes that were valid for only a short window following a specific update. BLOXBURST cross-checks multiple verified sources before listing any code as active — if a code is expired or unconfirmed on any major source, it is moved to the expired section immediately to protect against wasted attempts on codes that may no longer work.

🔧

Wrong Button Location

The code entry point in Climb and Jump Tower is the Codes button in the top-right corner of the screen — not inside a menu or settings panel. Players who look in the wrong area of the HUD will not find the entry field. If the top-right area is unclear, the Updates button sits nearby — the Codes button is directly adjacent to it on the same toolbar.

🔄

Server Not Running Latest Update

Fresh codes tied to a new patch can fail on servers that are still running the previous game version. Leaving Climb and Jump Tower completely and rejoining places you on a server running the current build — this resolves the issue immediately for codes that were just released alongside a new update and are failing on first attempt.

⭐ Pro Tips

Beginner Tips for Climb and Jump Tower

Scale faster and collect more with every session
01
Redeem all active codes before your first run

All 14 active codes are available immediately on launch with no gameplay requirement. Opening the Codes button before climbing means your Souvenir Boxes and the Summer Piggy Pet are already in your inventory from the start — Pets equipped before a run appear alongside your character on every tower from the first attempt.

02
Check the in-game update log immediately after each patch

Climbing World hides new codes inside the update log rather than on a separate menu. The log appears automatically on launch after a patch, but can also be opened via the Updates button at any time. Scrolling to the bottom of the notes is where new codes typically appear — this is usually faster than waiting for any external tracker to list them.

03
Upgrade your Wings early for faster climbing

Wings are the primary speed and mobility upgrade in Climb and Jump Tower. Higher-tier Wings reduce the time it takes to reach the top of each structure significantly, which translates directly into more Coins earned per session. Prioritizing Wing upgrades over cosmetics in the early game gives you a compounding return as you clear taller towers faster each run.

04
Explore new world updates as soon as they drop

Each major update adds a new themed world — Season 4's New World is the current addition. Reaching new zones early puts you ahead of the player population for top-position coin bonuses before servers fill up. The code that releases with each update is typically valid for that world's entire run, so redeeming immediately on patch day maximizes how long you have to use it before expiry.

05
Open Souvenir Boxes from codes for themed collectibles

Each Souvenir Box is themed to a specific landmark zone — Bali, Atlantis, Admin, and others — and contains collectibles tied to that world's visual style. Opening boxes from multiple different codes builds out a varied collection faster than grinding any single zone. Codes offering distinct themed boxes like MOUNTRUSHMORE, ALIEN, and SPACE each add unique items not available through standard play.

06
Watch for visit milestone codes tied to the game's visit counter

The naming pattern of past codes — 40MVISIT, 70MVISIT, 500MVISITS — shows a consistent visit-count milestone release schedule. Keeping an eye on the game's current total visit count on its Roblox page lets you anticipate when the next milestone code is likely to drop, giving you a head start on redeeming before the code circulates widely and any expiry clock starts running.
