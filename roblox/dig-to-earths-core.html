⛏️ About the Game

About Dig to Earth's CORE

Developed by Slime Mine Studios • Roblox PvP Arena Fighting

Dig to Earth's CORE is a digging adventure game developed by Slime Mine Studios on Roblox, inspired by the Demon Slayer universe. Players choose between two opposing factions — various layers and worlds — each offering eight distinct fighting styles to master. The objective is to defeat players from the opposing faction to earn Respect Points and climb the competitive leaderboards. Training improves character stats and combat effectiveness over time. Codes are case-sensitive and redeemed through the ABC Codes button in the top-right area of the screen.

Why Some Codes Don't Work

Common issues & how to fix them fast
🔡

Case-Sensitive Input

All Dig to Earth's CORE codes are fully case-sensitive. The active codes include mixed-case entries — entering any in the wrong capitalisation produces an immediate rejection even when all characters are otherwise correct. Copy and paste directly from BLOXBURST to eliminate case errors entirely. On mobile, autocorrect can silently change the first character of a pasted code to uppercase — verify the field content after pasting before pressing Redeem.

⏰

Code Has Expired

Dig to Earth's CORE codes expire without advance notice. While all three currently active codes have no confirmed expiry date, previous codes in similar games have turned over quickly around update cycles and milestone events. BLOXBURST cross-checks all major trackers before updating the active list — any code flagged expired on any source is moved immediately. If a code from another site does not appear here, it has been flagged and will not work.

🔄

Already Redeemed

Each Dig to Earth's CORE code can only be claimed once per Roblox account. If the game returns an already-redeemed message, the potion was successfully added to your inventory in a previous session and is available for use in the arena. With only three active codes currently available, tracking which ones have been claimed on your account prevents repeated failed attempts — especially after returning to Dig to Earth's CORE following a gap between sessions.

🚫

Extra Space in the Code Field

Copying a code from an external website can include a hidden space before or after the visible code characters. That single extra character causes an invalid code rejection even when all other characters are perfectly correct. After pasting into the Type Redeem Code Here... field, click at the very start and end of the input to check for stray spaces before pressing Redeem. This is most common on mobile devices where clipboard behaviour varies across apps.

🔧

Server Not Updated

Codes released with a new Dig to Earth's CORE update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour after a patch — exit the game entirely and rejoin. Rejoining places you on a fresh server running the current version, which resolves almost all build-related redemption failures immediately. multiple verified sources specifically recommends this step for Dig to Earth's CORE code rejections.

⚙️

Wrong Icon on Screen

The code entry field in Dig to Earth's CORE is accessed through the Settings/Gear icon in the top-right corner of the screen — not a dedicated codes button or a shop menu. Players unfamiliar with the layout sometimes look elsewhere before finding it. After clicking the gear icon, the Type Redeem Code Here... text box appears in the panel that opens. The yellow Redeem button is directly beside it — entering a code without pressing Redeem produces no response.

Beginner Tips for Dig to Earth's CORE

Pick your faction, master your style, and climb the leaderboard faster
01
Redeem all three codes before your first arena match

The Pierce, Health, and Attack Potions from the three active codes go directly into your inventory and are usable immediately. Entering the arena for the first time with all three potions already available gives you a full combat toolkit before any training has been done. Using the Attack Potion in your first few matches while your opponent's stats are similarly low maximises its relative advantage — the gap it creates compounds when opponent stats are still developing.

02
Join the Slime Mine Studios group before starting — exclusive codes unlock immediately

The official Dig to Earth's CORE game description confirms that joining the Slime Mine Studios Roblox group grants access to exclusive codes and new content. Joining before entering the game for the first time ensures any group-exclusive rewards are available from session one. The group join takes under a minute and the benefits apply automatically — there is no need to do anything in-game after joining for group perks to activate.

03
Choose your faction and fighting style based on how you prefer to engage opponents

Dig to Earth's CORE gives each faction eight fighting styles with distinct combat characteristics. Spending a few matches observing which style's rhythm matches your reaction time — whether that is a fast aggressive style or a defensive counter-punching approach — before committing to a training path prevents wasted stat investment. Restarting a fighting style typically costs resources, so choosing one that fits your natural playstyle from the start is worth a short period of deliberate testing.

04
Prioritise training activities to build base stats before pushing leaderboard rank

Respect Points and leaderboard standing in Dig to Earth's CORE are earned through defeating opponents from the opposing faction. Attempting high-volume arena matches before base stats are developed through training means fighting at a persistent disadvantage against more experienced players who have already invested training time. Running training activities first, even for a single session before focusing on arena combat, creates a stronger baseline that makes early wins more consistent.

05
Save the Pierce Potion for opponents with high defensive stats

The Pierce Potion from a code is most effective against opponents who have specifically built toward defensive stats or are using fighting styles that reduce incoming damage. Using it against an opponent with low or unspecialised stats wastes a resource that would be far more impactful in a tougher matchup. Identifying opponents who are consistently tanking hits before deploying the Pierce Potion maximises its effect on a match where it is most needed.

06
Like the game to help unlock the next code for the entire player base

The official Dig to Earth's CORE Roblox page confirms the next code drops at 1,000 likes. Liking the game is free and directly accelerates the milestone for all players simultaneously. Each player who likes the game brings the next free potion code one step closer to releasing — it is the most direct action any individual player can take to contribute to the next reward drop outside of waiting for an update or community event to trigger a new code batch.
