🚗 About the Game

About Build A Pet Factory

Developed by Truly Interactive • Roblox Pet Factory Tycoon

Build A Pet Factory is a pet tycoon simulator on Roblox developed by Truly Interactive. Players construct and optimise a production line that manufactures pets — purchasing spawners to generate them, placing upgraders to increase their sale value, and laying conveyors to route them toward Sell Points. Cash earned from pet sales is reinvested into bigger spawners, additional upgraders, and factory expansion. Gems are the premium currency used in the gem shop for exclusive upgrades and hatching pets, but the gem shop and pet hatching system are locked behind the Rebirth mechanic. Rebirthing resets the factory for a permanent multiplier bonus — many late-game features only become accessible at 10 or 20 Rebirths. Code rewards provide Cash and Gems that allow new players to progress faster through early Rebirth thresholds. Updates drop every Saturday, and new codes are released alongside each patch.

🏭 Gameplay

Each factory session begins with purchasing a Pet Spawner from the Shop to begin producing pets. Conveyors route pets from spawner to Sell Point, converting them to Cash automatically on arrival. Upgraders placed along the conveyor belt increase pet value before the sell — positioning them immediately before the Sell Point gives the highest value increase per pet. Cash is reinvested into additional spawners and higher-tier upgraders to compound output. Rebirthing resets the current factory but grants a permanent multiplier, unlocking the Gem Shop, pet hatching, and luck-boosting building parts unavailable below 10 Rebirths.

🎁 Code Drops

Build A Pet Factory updates every Saturday, and new codes are released alongside each weekly patch. Codes are announced in the official Discord server's dedicated codes channel before appearing on any external tracker. The developer also posts announcements on the official X account and YouTube channel for each update. Codes are case-sensitive — redeem them as soon as possible as they can expire without warning.

Why Some Codes Don't Work

Common issues & how to fix them fast

Rebirth Requirement Not Met

Two active codes require specific Rebirth counts before they function — the code requiring 10 Rebirths returns an error for accounts below that threshold, and the code requiring 20 Rebirths does the same. This is not a typo or expiry issue. The code input box will accept the code but reject it with an error until the Rebirth requirement is met. Once you hit the required count, return to the Shop → Codes panel and redeem immediately — these codes will not expire before you reach the threshold in normal play.

🔡

Case-Sensitive Typo

Build A Pet Factory codes are case-sensitive. All four currently active codes are fully lowercase — entering any letter in uppercase will cause the Claim button to reject the code. Copy and paste directly from BLOXBURST to avoid capitalisation errors. If a code still fails after pasting, check for an accidental leading space before the first character, which can occur during copy-paste on mobile.

Already Redeemed

Each Build A Pet Factory code is one-time use per account. If a code was redeemed in an earlier session before a factory reset or Rebirth, the Cash reward was added to the pre-reset balance and may no longer be visible. A "code already redeemed" error confirms the reward was successfully collected at some point — checking your Gem count against the 667 Gems from supernice is the quickest way to confirm whether that specific code was previously claimed.

⭐ Pro Tips

Beginner Tips for Build A Pet Factory

Build a faster factory and make the most of every code reward
01
Redeem all codes immediately before building anything

All four active codes provide Cash and Gems before any factory income begins. Redeeming them before placing a single spawner gives you a larger starting pool to invest in better-quality spawners and more upgraders from the first session — rather than starting with only enough cash for the cheapest spawner and waiting for initial income to accumulate.

02
Place upgraders immediately before your Sell Point

Upgraders increase the sale value of pets as they pass through on the conveyor belt. Positioning upgraders in the last section of conveyor before the Sell Point — rather than near the spawner — maximises value increase per pet since pets gain the full upgrade bonus immediately before being sold. Adding multiple upgraders in sequence further compounds the multiplier on each sale.

03
Plan your first Rebirth around Cash surplus, not just income rate

Rebirthing resets the factory to zero Cash but grants a permanent multiplier. The optimal time to Rebirth is when accumulated Cash from the current run can fund a faster initial rebuild than the previous session — meaning you can reach your previous factory output level more quickly after each reset. Rebirthing too early with insufficient knowledge of efficient layouts extends rebuild time beyond the multiplier benefit.

04
Save code-earned Gems for pet hatching after 10 Rebirths

The Gem Shop and pet hatching are locked until 10 Rebirths. Gems received from the active supernice code are stored in your account regardless of Rebirth count — they do not reset with the factory. Holding the 667 Gem reward until reaching 10 Rebirths provides an immediate hatching pool at the earliest point the system unlocks, rather than grinding the first hatch from zero gems.

05
Use conveyors to route pets efficiently — avoid dead ends

Conveyors determine the path pets travel from spawner to Sell Point. Pets that reach a dead end stop generating income until the layout is corrected. Planning the conveyor route before placing spawners and upgraders prevents layout corrections mid-session that require selling and repurchasing components. A straight line from spawner through upgraders to Sell Point is the most reliable early layout before more complex multi-line setups become affordable.

06
Check the codes panel after each Saturday update

Build A Pet Factory releases new content and codes every Saturday. The codes panel in the Shop menu takes under 30 seconds to check — making it a low-effort habit at the start of each weekly session. Since all existing active codes have no expiry conflicts across any major tracker, newly added Saturday codes are the only source of additional code rewards currently worth monitoring.
