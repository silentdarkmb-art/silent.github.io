How to Redeem Codes

  1. Launch Brainrot Evolution on Roblox and wait to fully load into the game.
  2. Click the Shop icon on the left side of the screen to open the Shop menu.
  3. Select the Codes tab on the right edge of the Shop window — it sits at the far right of the Shop panel, not at the top.
  4. Enter your code in the Enter Code text box — codes are not case-sensitive — then click the green Verify button to collect your free EXP Potions, Mega EXP Potions, or Crates instantly.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
🚗 About the Game

About Brainrot Evolution

Developed by Brainrot Evolution • Roblox Incremental Evolution Simulator

Brainrot Evolution is an incremental evolution simulator on Roblox developed by Brainrot Evolution. Players eat to gain levels, unlock new Brainrot characters at each tier, and evolve through hundreds of forms — from Level 1 through Level 999 and beyond. Battles, Raids, and boss fights earn Wins and Pets that provide passive stat multipliers. EXP Potions double the rate of experience earned for a set duration, while Mega EXP Potions provide triple XP. Crates drop random Relics — accessories like shades and sneakers — that buff active Brainrots with additional bonuses. Codes are not case-sensitive and are released every Saturday alongside weekly updates, as well as when the game hits social milestones. Premium players receive a permanent bonus of 10% additional Wins and 10% additional EXP per session.

What Do Codes Give You?

Free rewards claimable directly on your account
⚗️

Mega EXP Potions

The most valuable code reward in Brainrot Evolution. Mega EXP Potions activate triple XP for a set duration, dramatically accelerating level progression toward new evolution unlocks. Most active codes award between 2 and 5 Mega EXP Potions per redemption. Activating all potions back-to-back extends the triple XP window without interruption, making code redemption most effective immediately before a focused grinding session.

Most Valuable
🧪

EXP Potions

Standard EXP Potions double XP earned for a set duration — less potent than Mega EXP Potions but still a meaningful progression boost. Several active codes award EXP Potions rather than the Mega variant. Stacking EXP Potions before a session provides sustained double XP across multiple evolution thresholds, which is most effective when grinding toward a distant tier unlock.

Progression
📦

Crates

Crates drop random Relics when opened from the inventory — accessories such as shades, sneakers, and other gear that apply passive stat bonuses to active Brainrots. Specific crate types tied to individual characters have appeared in past code rewards. Crates are one of the only ways to obtain Relics without direct purchase, making code-exclusive crate drops among the most inventory-impactful rewards currently available.

Random Relics
🎫

Void Tickets & Event Rewards

Void Tickets unlock Void-tier content and special event challenges outside the standard evolution path. Past codes have awarded both single Void Tickets and bundles of 30. Event-specific rewards — including Vault Crates and Gingerbread Crates — have also appeared during seasonal periods. These tend to be the rarest code reward types and are not available outside the event windows in which they were released.

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Expired Between Saturday Updates

Brainrot Evolution codes released with one Saturday update tend to expire when the following Saturday's patch goes live. If a code from BLOXBURST's active list returns an error mid-week, it may have been deactivated early due to a hotfix or mid-week content patch — the developer occasionally pushes smaller patches outside the Saturday schedule. Check BLOXBURST for updated status before assuming a typo.

🔡

Space Missing in Multi-Word Codes

Brainrot Evolution codes are not case-sensitive, but spelling and spacing must be exact. Multi-word codes with a space between words — like past codes with compound names — fail if the space is omitted or replaced with an underscore. Copy and paste directly from BLOXBURST to preserve all spacing and characters exactly as listed.

🔄

Already Redeemed

Each Brainrot Evolution code is one-time use per account. Given the weekly update cadence and large historical code list, it is easy to forget which codes were redeemed in previous sessions. Check your current EXP Potion and Mega EXP Potion count in inventory against the expected total from all active codes to confirm whether specific codes were already claimed before retrying them.

📋

Conflict Between Sources

Different trackers showed major disagreement — one source listed over 60 active codes while a fresher source had already moved the majority to expired. BLOXBURST uses the most recently updated source and removes any code present in its expired section immediately — this reduced the active list to only codes confirmed active across the freshest available data.

🔧

Server Not Updated

New Brainrot Evolution codes released with a Saturday update occasionally fail on servers still running the previous build. Closing the game entirely and rejoining places you on a server running the current patch. This resolves the majority of cases where a code confirmed active by multiple sources still returns an error on first attempt.

⚙️

Wrong Menu Location

The code redemption panel in Brainrot Evolution is inside the Shop menu, not on the main screen or in a settings panel. Click the Shop icon on the left side of the screen, then select the Codes tab on the right edge of the Shop window — it is easy to miss as it sits at the far right rather than at the top or centre of the menu. Enter your code in the text box and click Verify to claim rewards.

⭐ Pro Tips

Beginner Tips for Brainrot Evolution

Level up faster and get the most from every Brainrot Evolution code reward
01
Activate Mega EXP Potions before a dedicated grinding session

Mega EXP Potions provide triple XP for a set duration — their value is proportional to how much EXP you earn while active. Claiming and immediately activating all code-earned Mega EXP Potions right before a focused session, rather than saving them, maximises the return since the timer begins on activation rather than on redemption.

02
Redeem new codes on Saturday before playing

Since Brainrot Evolution updates every Saturday, the freshest codes are available at the start of each weekly session. Checking BLOXBURST or the Discord announcements channel at the start of each Saturday session and claiming all new codes before opening the game provides the maximum XP boost available for that week's grind.

03
Save Crates until you identify which Relics are missing

Crates drop random Relics from the current pool — opening them immediately without knowing which Relics you already own may produce duplicates that provide no additional benefit. Checking your existing Relic inventory before opening code-earned Crates helps identify gaps, though the random nature of crate drops means outcomes cannot be controlled regardless of timing.

04
Focus on Raid and boss fights to accelerate Pet collection

Pets earned through Raids and boss fights provide permanent passive multipliers that stack across all subsequent sessions. Unlike EXP Potions — which provide a temporary boost — Pets improve baseline EXP gain permanently. Prioritising Raid participation over standard grinding during early sessions builds a stronger permanent multiplier stack before code-earned Potions are activated, compounding the total benefit of each potion use.

05
Use the Fusion Machine once per update to check new recipes

The Fusion Machine system added in a recent update allows players to combine Secret Brainrots into new and stronger Secret variants using specific recipes. New recipes are added with each Saturday update. Checking the Fusion Machine panel at the start of each weekly session reveals any new combinations available — Secret Brainrots sitting in inventory uncombined provide no passive benefit until fused into a higher-tier form.

06
Premium players: stack Mega EXP Potions with the base 10% bonus

Premium Roblox players in Brainrot Evolution receive a permanent 10% EXP bonus on top of standard gains. When a Mega EXP Potion is active, the triple XP multiplier applies to the already-boosted base rate — making the effective gain higher than triple for Premium players compared to non-Premium. Activating code-earned Mega EXP Potions during Premium-active sessions produces the highest combined XP output available in the game without additional purchases.
