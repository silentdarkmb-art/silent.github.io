🧸 About the Game

About Dolly's Factory

Developed by The Forever Studio • Roblox Plushie Survival Horror

Dolly's Factory is a Roblox plushie survival horror game developed by The Forever Studio. Players take the role of a living plushie navigating a mysterious and dangerous toy factory. The core loop involves travelling through different zones to power up machines while avoiding lurking threats known as Rejects — animatronic enemies that patrol the factory floor. Each plushie character has distinct abilities that affect how players interact with the environment and evade danger. DollyBucks are the game's primary currency, earned through gameplay and code redemptions, and spent on new plushie characters, skins, charms, and emotes. Codes are case-sensitive and redeemed through the Codes button at the top of the screen — it has a bird and letter icon — confirmed by multiple verified sources GameRant, multiple verified sources, and the official the official game wiki.

Why Some Codes Don't Work

Common issues & how to fix them fast
🔡

Case-Sensitive Input

All Dolly's Factory codes are fully case-sensitive — confirmed by multiple verified sources. The active codes include all-lowercase, all-caps, and mixed-case entries — entering any in the wrong capitalisation causes an immediate rejection even when all other characters are correct. multiple verified sources specifically recommends copying and pasting from a verified list rather than typing manually. On mobile, autocorrect can silently change the first character — verify the entry after pasting before pressing Redeem.

⏰

Code Has Expired

Dolly's Factory codes expire without advance notice — multiple verified sources specifically warns that codes can expire without warning. BLOXBURST cross-checks multiple verified sources before updating the active list. Any code showing "Check" or unverified status on multiple verified sources is moved to expired immediately — FEEDBACK was moved this way despite appearing active on other trackers. If a code from another site does not appear here, it has been flagged and will not work.

🔄

Already Redeemed

Each Dolly's Factory code can only be claimed once per Roblox account — confirmed by multiple verified sources and the official the official game wiki. If the game returns an already-redeemed message, the DollyBucks were added to your account in a previous session. With 19 active codes currently available, keeping a note of which ones have been claimed prevents repeated failed attempts — especially after returning to the game following a break during which several new codes may have been added and others claimed.

🔧

Old Server After Update

Codes released with a new Dolly's Factory update can fail on servers still running the previous build. multiple verified sources confirms that if a code fails, closing the game, reopening it, and trying again resolves the issue by placing the player on a fresh server with the current version installed. This is particularly relevant given that new codes are posted in the game-updates channel alongside major patches — rejoining immediately after a patch announcement ensures redemption takes place on an updated server.

🚫

Extra Space in the Code Field

Copying a code from an external website can include a hidden space before or after the visible characters. That single extra space causes an invalid code error even when all other characters are correct. After pasting into the code entry field, click at the very start and end of the input to check for stray spaces before pressing the pink Redeem button. This is most common on mobile devices where clipboard paste behaviour varies across browsers and apps without any visible indication of the extra character.

📍

Wrong Button on Screen

The code entry field in Dolly's Factory is accessed through the Codes button at the top of the screen — identifiable by its bird and letter icon — confirmed by multiple verified sources GameRant, multiple verified sources, and the official the official game wiki. The button is located in the row of UI buttons at the top centre of the screen. Players who look for a settings menu or a shop panel will not find the code entry field there — it is only accessible through the Codes button on the main game screen during the lobby or pre-run phase.

Beginner Tips for Dolly's Factory

Survive the factory longer and unlock better plushies faster
01
Redeem all 19 active codes before choosing your first plushie

DollyBucks from code redemptions go directly into your balance and are available immediately in the shop. Redeeming all 19 active codes before the first factory run — including the two high-value codes worth 1,000 and 1,500 DollyBucks respectively — gives a significant starting balance. Using that balance to purchase a plushie with stronger survival abilities from the start makes the early factory runs more manageable than using the default character while earning DollyBucks through runs alone.

02
Learn each plushie's unique ability before buying one with code DollyBucks

Each plushie character in Dolly's Factory has a distinct ability set that affects how they interact with the factory environment and evade Rejects — confirmed by multiple verified sources and the official the official game wiki. Spending code DollyBucks on the first available plushie without comparing abilities risks purchasing one that does not suit your playstyle. Reviewing ability descriptions in the shop before committing ensures the code balance is invested in a character that actually improves survivability for how you prefer to play.

03
Power up machines carefully — wrong button presses alert nearby Rejects

The core factory loop requires interacting with machines to power them up and progress to the next zone. multiple verified sources specifically confirms that pressing the wrong button during a machine checkup alerts nearby Rejects, forcing an immediate evasion. Taking a brief moment to identify the correct interaction before committing prevents unnecessary Reject attention that can derail an otherwise clean run. Shields and instant repair items can compensate for mistakes — but they are limited resources best saved for unavoidable encounters rather than self-inflicted alerts.

04
Help teammates complete tasks — group assistance earns bonus DollyBucks

multiple verified sources confirms that helping other players complete tasks and escape to the next area earns free DollyBucks on top of the base run reward. Actively assisting teammates with machine tasks — rather than focusing purely on individual survival — compounds DollyBuck earnings per session. Over multiple runs, the cooperative bonus DollyBucks represent a meaningful additional income stream that, combined with code redemptions, accelerates the timeline to affording higher-tier plushies and exclusive charms.

05
Save Shield and Heal items for Reject encounters rather than using them early

Shield and Heal items drop randomly during factory runs and are among the most direct ways to survive Reject encounters without needing to fully evade. multiple verified sources notes these items as critical survival resources in Dolly's Factory. Using them early during low-risk phases of a run — before Rejects become active or aggressive — wastes resources that would be far more impactful during the later, higher-intensity phases of longer runs where Reject density increases and evasion space tightens.

06
Check the Discord game-updates channel after every major patch for new codes

multiple verified sources and the the official game wiki both confirm that new codes appear in the Discord server's game-updates channel alongside major update patch notes. The developer embeds codes within update announcements rather than posting them as standalone messages — skimming the features list at the bottom of each update post is the specific tip multiple verified sources recommends. Given multiple verified sources's confirmation that codes release approximately every three weeks with updates, this channel check after each patch is the most reliable early-discovery method available.
