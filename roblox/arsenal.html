How to Redeem Codes

  1. Launch Arsenal on Roblox and wait on the main menu screen — codes cannot be redeemed mid-match.
  2. Click the Gift Icon at the bottom-left of the main menu screen to open the code redemption window.
  3. Type or paste your code into the Enter Code Here text box — codes are fully case-sensitive, including spaces in codes like wake up.
  4. Press the REDEEM button to claim your free Skins, Announcer Packs, BattleBucks, or Kill Effects instantly. Code-exclusive items appear with a yellow blip in your inventory.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
🚗 About the Game

About Arsenal

Developed by ROLVe • Roblox Fast-Paced FPS Shooter

Arsenal is a fast-paced FPS deathmatch developed by ROLVe, one of Roblox's most established shooter studios. Players cycle through a weapon loadout with every kill — each eliminated opponent advances you to the next gun in the sequence. The player who reaches and wins a kill with the final Golden Weapon wins the round. With nearly 150 weapons spanning bazookas, spell books, melee tools, and standard firearms, no two kills feel the same. BattleBucks earned in matches fund cosmetic purchases — characters, skins, kill effects, taunts, and more — all collected in a personalised loadout. Codes unlock exclusive cosmetics unavailable in the standard shop, including code-only Announcer Packs voiced by community figures and limited character skins tied to specific update milestones.

🎮 Gameplay

Join a deathmatch server and cycle through Arsenal's 150-weapon rotation with each kill. Landing a kill advances you to the next weapon in sequence — from conventional rifles to absurd bazookas and spell books. Reach the Golden Weapon last and score one final kill to win the match. Joining the ROLVe Roblox group grants a 25% BattleBucks and XP bonus on every match played, accelerating cosmetic collection.

🎁 Code Drops

ROLVe releases Arsenal codes infrequently compared to most Roblox games — drops are tied to major updates, seasonal events like the Dustfall update, and milestone moments. Codes are announced on the official ROLVe Discord server and via @ROLVeStuff on X. Many Arsenal codes are permanent cosmetic unlocks rather than timed rewards, making them worth redeeming at any point even if they have been active for months.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Cosmetic Code Expired Without Warning

Arsenal codes for skins and announcer packs expire without any advance notice from ROLVe. If a code you previously saw listed as active now returns "This Code Does Not Exist," it has been deactivated — the cosmetic is no longer obtainable from that code. Redeeming all active codes on the same session you find them is the only reliable protection against silent expiry.

🔡

Case-Sensitive Typo

Arsenal codes are fully case-sensitive — scarybug uses all-lowercase, 10YRS uses all-caps, and wake up includes a space. A single wrong capital, missing space, or extra character causes the REDEEM button to reject the entry with a "This Code Does Not Exist" message. Copy and paste directly from BLOXBURST to avoid any input error.

🔄

Already Redeemed

Each Arsenal code is one-time use per account. If you enter a code and receive no reward or no confirmation, check your inventory for the cosmetic — Arsenal does not always display a visible "already redeemed" message. Code-exclusive items are marked with a yellow blip in your inventory to confirm successful redemption.

📋

Conflict Between Sources

Arsenal trackers frequently disagree on active status — F00LISH, JOHN, ANNA, and PET appear active on Beebom but confirmed expired on Pocket Tactics on the same date. BLOXBURST cross-checks Beebom, Pocket Tactics, and Sportskeeda before listing — any code that appears in the expired list of any major tracker is moved directly to our Expired section.

🔧

Server Not Updated

Newly released Arsenal codes tied to the latest update can fail on servers still running the previous patch. Closing Arsenal completely and reopening it places you on a fresh server running the current build. This resolves most "This Code Does Not Exist" responses on codes that are confirmed active but were just released alongside a new patch.

⚙️

Wrong Button Location

The code input in Arsenal is accessed through the Gift Icon at the bottom-left of the main menu screen — not through any settings, pause screen, or in-match UI. Click the gift icon to open the code redemption window, then enter your code and press REDEEM. The redemption window is only accessible from the main menu, not mid-match.

⭐ Pro Tips

Beginner Tips for Arsenal

Customise your Arsenal loadout and get the most out of every code reward
01
Redeem all active codes from the main menu before your first match

Arsenal code redemption is only available from the main menu — not mid-match. Claiming all active codes in a single session before queuing ensures you enter your first match with every available cosmetic, announcer, and BattleBucks reward already secured in your inventory.

02
Join the ROLVe Roblox group before your first match

Joining the ROLVe group at roblox.com/communities/2613928 before playing grants a permanent +25% BattleBucks and XP bonus on every match. This bonus is always active as long as you remain in the group — stacking it with active code BattleBucks rewards like merrychristmas25 and TRGTBOARD gives you the maximum possible currency income from the very first session.

03
Prioritise code-exclusive cosmetics over shop purchases

Arsenal code cosmetics — skins, announcer packs, kill effects — are permanently unobtainable through BattleBucks once the code expires. Shop items remain available indefinitely. Spending BattleBucks on shop cosmetics before claiming all active codes risks losing access to code-exclusive items that can never be bought back regardless of how much currency you accumulate later.

04
Set your preferred announcer before queuing

Arsenal lets you select your active announcer from your inventory in the main menu. Switching to a freshly-claimed code announcer — Flamingo, Bandites, Enforcer, Xonae, or EPRIKA — before entering a match means you hear their voice for the full session. Each announcer has unique lines for kills, streaks, and round wins that change the feel of every match.

05
Use the Fate map code for a solo exploration session

The FATE code teleports you directly to Arsenal's hidden Fate map with no other players present. This private session lets you explore the map layout, practice movement, and learn spawn positions without the pressure of live opponents — a useful preparation tool before facing the map in standard ranked or casual deathmatch play.

06
Enable notifications on ROLVe's #codes Discord channel specifically

Arsenal codes drop infrequently — sometimes with gaps of weeks between drops. Rather than enabling full-server Discord notifications, enabling notifications only on the #codes channel in the ROLVe Discord gives you a targeted alert whenever a new code is posted, without noise from the many other active channels in the server.
