⚡ About the Game

About Flashpoint

Developed by Varis Studios • Roblox Superhero Racing and Combat

Flashpoint (formerly Flashpoint: Worlds Collide) is a superhero racing and combat game developed by Varis Studios on Roblox, set in the DC universe of the Flash. Players choose a speedster, race other players across an open city, fight criminals, and unlock new suits and abilities through levelling and code rewards. The Rebirth system allows players to reset their level for escalating bonuses, extending the progression loop significantly. To redeem codes, players must first join the Varis Studios Roblox group and like the game — both steps are required before the code system accepts any input.

🎁 Rewards

What Do Codes Give You?

Free Cash, EXP, Rebirth Tokens, and exclusive Suits
💰

Cash

Cash is Flashpoint's primary currency, used to purchase suits and upgrades in the game store. Larger code drops have awarded batches of up to 150,000 Cash per redemption — representing a substantial shortcut to expensive suits that would otherwise require many hours of racing and crime-stopping income. Cash codes are the most frequent reward type in Flashpoint's history, appearing across both milestone drops and event-specific releases, making them the most consistently available free resource for active players.

Primary Currency
💫

EXP

EXP points advance character level in Flashpoint, unlocking new abilities and improving base stats across racing and combat encounters. Most code drops pair EXP awards with Cash in matching quantities — the largest drops have awarded 150,000 EXP simultaneously. Levelling through code-boosted EXP accelerates access to Rebirth, which resets the level counter in exchange for multiplying bonuses. Players who redeem EXP codes immediately before a planned Rebirth get the full level-up benefit without grinding the final stretch before the reset.

Progression
🔄

Rebirth Tokens

Rebirth Tokens allow players to trigger the Rebirth mechanic — resetting their level in exchange for escalating permanent bonuses — without grinding to the required level cap first. Multiple codes have awarded between 1 and 3 Rebirth Tokens per drop, making them among the highest-value rewards in Flashpoint's code history. A single token represents the full grind of an entire level cycle compressed into a single code redemption, which compounds significantly for players who stack tokens across multiple drops before using them in sequence.

Rebirth Mechanic
🎽

Suits

Suit codes unlock specific named speedster outfits that are exclusive to the code at the time of release and cannot be purchased with Cash. Past suit codes have awarded named cosmetics including the Luck Runner Suit, SURGE Suit, Suicide Squad Flash Suit, and others tied to specific updates, events, and collaborations. Suit codes are typically released around seasonal events and content updates — the St. Patrick's Day suit code being the most recent example — making seasonal periods the most predictable windows for upcoming suit drops.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
👥

Group Not Joined or Game Not Liked

Flashpoint codes will not activate unless the player has joined the Varis Studios Roblox group AND liked the game — both steps are mandatory prerequisites. Skipping either one causes the code to reject immediately regardless of whether the code itself is valid and still active. After completing both steps, the game must be fully restarted before attempting any code redemption. Players who have already joined the group and liked the game in a previous session do not need to repeat these steps — they only need to be completed once per account.

⏰

Code Has Expired

Flashpoint codes expire without advance notice and some carry explicit short expiry windows — the unctommy code expired on March 21, happypatrick!! expired approximately one week after March 17, and yayspring!! was flagged as expiring very soon across multiple sources at time of checking. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code from another source does not appear in the active list here, it has been flagged and will not work.

🔡

Case-Sensitive Input

All Flashpoint codes are fully case-sensitive and several active codes are unusually long, containing mixed capitalisation, punctuation, and special characters including exclamation marks and colons. Entering any character incorrectly produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Redeem, particularly for the longer mixed-case codes in the active list.

🔄

Already Redeemed

Each Flashpoint code is single-use per Roblox account. If the game returns an already-redeemed message, the Cash, EXP, or Rebirth Token was added to your account in a previous session. With a long history of milestone and event codes dating back through 2025, players returning after a gap may have claimed codes they no longer remember redeeming — particularly larger drops that were active for extended periods. Checking the active list against memory before attempting codes prevents repeated failed attempts.

🔧

Old Server After Update

Codes released with a new Flashpoint update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately. Rejoining also resets any session-specific issues that may be affecting code input without requiring any other troubleshooting steps.

🚫

Extra Space in the Code Field

Copying a code from an external source can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. This is particularly common with Flashpoint's longer codes, where a stray space at the start or end of the pasted text is difficult to detect visually in the input field. After pasting, click at the very start and end of the code field to check for extra spaces before pressing Redeem. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

⭐ Pro Tips

Beginner Tips for Flashpoint

Speed through levels, master Rebirth, and never miss a code drop
01
Join the Varis Studios group and like the game before anything else — codes won't work without both

Both the group join and the game like are mandatory prerequisites for Flashpoint code redemption — skipping either step causes all codes to reject immediately, regardless of whether the code is valid. Completing both steps before the first session and restarting the game clears the prerequisite check for all future sessions on that account. The group join also unlocks free suits available to members, making it a dual-purpose step that provides value beyond just enabling code redemption.

02
Save Rebirth Tokens from codes until you have enough Cash to purchase the suit you want first

Rebirth resets your level and Cash balance in exchange for compounding bonuses. Using a Rebirth Token immediately after redeeming a code that also awarded Cash means the Cash is wiped in the same session. Spending the code-awarded Cash on suits or upgrades before triggering Rebirth preserves the value of both rewards simultaneously. Stacking multiple Rebirth Tokens across several code drops before using them in sequence also compounds the bonus multiplier more effectively than using each token individually as it is earned.

03
Claim Daily Rewards and the group suit every session before racing or fighting criminals

Flashpoint's Daily Rewards system awards escalating Cash and EXP bonuses for consecutive logins, and the Rewards tab at the upper right of the screen provides additional free items on a regular cycle. Claiming both before any active gameplay ensures the session's passive income is secured before any risk of disconnection or session ending early. The developer also confirms that inviting five friends to the game awards 1,000 Cash — a one-time bonus that stacks directly on top of code rewards for players who haven't yet used the invite system.

04
Copy and paste every code — especially the longer ones — to eliminate input errors

Flashpoint has some of the longest codes of any Roblox game, with active codes exceeding 90 characters that include mixed capitalisation, exclamation marks, and colons. Typing these manually introduces a near-certain chance of error on at least one character. Copying directly from BLOXBURST and pasting into the code field eliminates this risk entirely. On mobile, long-press the field after pasting to verify the full code is present before pressing Redeem — the field may display a truncated version that makes it difficult to confirm the end of the code is intact.

05
Check the Discord code channel manually before each session — there is no automated alert

Varis Studios releases Flashpoint codes exclusively through the official Discord server, with no automated notification to ping players when a new code goes live. The only way to catch codes as soon as they drop is to check the code channel manually before each session, or to enable Discord notifications for that specific channel. Given that some Flashpoint codes carry confirmed short expiry windows of less than a week, the gap between a code releasing and it expiring can be shorter than the interval between two visits to an external tracker page.

06
Like the game on every account you play on — each like accelerates the next milestone code for everyone

Flashpoint's next milestone code is tied to the game's like count on the Roblox page. Liking is mandatory to enable code redemption on each account, but it also directly advances the community like count that determines when the next code drops for all players. Each player who completes the like step brings the next free Cash, EXP, or Rebirth Token code closer to releasing — making it one of the few individual actions in Flashpoint that benefits the entire player base simultaneously rather than just the account completing it.
