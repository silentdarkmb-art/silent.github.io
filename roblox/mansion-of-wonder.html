How to Redeem Codes

  1. Launch Mansion of Wonder on Roblox and load into the lobby.
  2. Walk forward to the Swag Booth — it is visible straight ahead when the game loads.
  3. Press E to interact with the fox NPC at the Swag Booth.
  4. Click Redeem Codes from the menu that pops up.
  5. Type or paste your code into the text box and click the orange checkmark to claim your free avatar item.
💬 Codes are case-sensitive — copy and paste directly to avoid errors. Rewards go to your Roblox avatar inventory and work in every Roblox game.
🏰 About the Game

About Mansion of Wonder🏰

Developed by Roblox Build It, Play It • Official Roblox Avatar Experience

Mansion of Wonder is an official Roblox experience created by Roblox Corporation as part of the Build It, Play It series, launched in June 2021. Like Island of Move, codes redeemed in Mansion of Wonder award free avatar items — including waist accessories, shoulder pieces, hats, and backpacks — that go directly into your permanent Roblox inventory and are wearable in every Roblox experience you play.

🎮 Gameplay

Players explore a themed mansion environment, interacting with various exhibits and activities. The primary appeal is the Swag Booth code redemption system, through which Roblox distributes limited promotional avatar items. The game has over 113 million visits and serves as one of Roblox Corporation's main platforms for releasing exclusive avatar accessories.

🎁 Code Drops

Mansion of Wonder codes are released by Roblox Corporation to celebrate platform milestones, seasonal events, and Build It, Play It promotions. Codes do not follow a predictable schedule and may expire without advance notice. All 5 current codes have been active since the game's promotional events and remain valid as of March 2026.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Has Expired

Mansion of Wonder codes are tied to Roblox promotional events and can expire without warning. If the game returns an invalid or expired error, the code is no longer active. Return to BLOXBURST for the most current verified list — we update immediately when codes expire.

🔡

Wrong Capitalization

Mansion of Wonder codes are case-sensitive. A code like ParticleWizard fails if entered as particlewizard or PARTICLEWIZARD. Copy and paste codes directly from BLOXBURST rather than typing them manually to prevent any capitalization errors.

🔄

Already Redeemed

Each Mansion of Wonder code can only be redeemed once per Roblox account. If the code has already been claimed, the game will display an already redeemed message. Open your Roblox avatar inventory to confirm whether the item was received during a previous session.

🏰

Wrong NPC or Location

Codes in Mansion of Wonder can only be entered through the Swag Booth — the fox NPC located directly ahead when you first spawn in. Pressing E anywhere else in the mansion will not open the code redemption menu. Walk directly to the Swag Booth before attempting to redeem.

🖊️

Extra Space in Code

An accidental space before or after the code text causes an invalid error even when the code itself is correct. After pasting a code, check both ends of the text box for stray spaces and remove them before clicking the orange checkmark to submit.

🔧

Outdated Game Server

Freshly released codes can occasionally fail on older servers that have not refreshed yet. If a brand new code isn't being accepted, exit Mansion of Wonder fully and rejoin — landing on a fresh server will have the latest code database loaded and should accept the code immediately.
