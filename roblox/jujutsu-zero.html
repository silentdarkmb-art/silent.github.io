⚡ About the Game

About Jujutsu Zero

Developed by Studio Resonance • Roblox Anime Action RPG Game

Jujutsu Zero is an anime action RPG developed by Studio Resonance on Roblox, inspired by the Jujutsu Kaisen series. Players explore a vast open world filled with cursed spirits, dangerous sorcerers, and powerful cursed objects — battling enemies and growing stronger through fast-paced, high-octane combat. Clans provide passive bonuses and define a part of your identity, while Innate Techniques and abilities from the series shape your combat style. Lumens are the primary currency for upgrades and progression, Clan Rolls let you reroll for a better clan, and XP Vows accelerate your leveling — all of which can be obtained for free through codes, giving you a strong early-game boost without the grind.

Lumens

Clan Rolls

Clan Rolls give you additional attempts to land a stronger Clan assignment for your character — a core mechanic in Jujutsu Zero that directly influences your passive bonuses, cursed technique compatibility, and overall combat potential. XP Vows are experience-boosting items in Jujutsu Zero that accelerate how quickly your sorcerer gains levels through combat, quests, and encounters across the game's world. Since Jujutsu Zero features a technique and skill progression system tied to your level, levelling up faster through XP Vows unlocks new abilities and Domain Expansion mechanics sooner — giving you a significant edge in the game's hectic PvP and PvE encounters. Activating an XP Vow before tackling challenging fights or quest chains maximises the boost's value.

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Typos & Case-Sensitive Input

Jujutsu Zero codes are case-sensitive — even a single wrong character will invalidate the code. Copy and paste directly from BLOXBURST to avoid input errors entirely. On mobile, autocorrect may silently alter a character after pasting, so always verify the text field before hitting Redeem.

🎓

Tutorial Not Completed

Jujutsu Zero requires you to complete the in-game tutorial before codes can be redeemed. The code menu will not be accessible until the tutorial is finished and you are dropped into the main game world. Complete the tutorial first, then return to the main menu to redeem your codes.

⏰

Code Has Expired

Codes in Jujutsu Zero can expire without any advance notice. BLOXBURST monitors multiple sources and removes any code the moment it shows expired or conflicting status. If a code is no longer on the active list here, it has already been flagged and will not work.

🔄

Already Redeemed

Each Jujutsu Zero code is single-use per Roblox account. If the game returns an already-redeemed message, the Lumens, XP Vows, or Clan Rolls were added to your account in a previous session. Check the active list before attempting codes to avoid repeated failed attempts.

🔧

Old Server After Update

Codes released alongside a new update can fail on servers still running the previous build. If a freshly announced code returns invalid — especially within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version.

🛍️

Wrong Menu Location

Jujutsu Zero codes can only be redeemed through the Codes button on the main menu screen — enter your code in the Enter Code Here text box and press Redeem to confirm. The Codes button appears on the main menu screen each time you load the game, not inside the game world itself.

⭐ Pro Tips

Beginner Tips for Jujutsu Zero

Start strong, roll smarter, and rise through the grades faster from your very first session
01
Redeem all active codes the moment you finish the tutorial — free spins and Lumens are critical early on

As soon as the tutorial ends, open the Codes menu from the main screen and redeem every active code before entering the open world. Current codes hand out hundreds of free Clan Rolls and thousands of Lumens — resources that would otherwise take hours of grinding to accumulate. Using these immediately gives you the spins needed to target a strong starting Clan before investing time into quests or combat.

02
Target a Special Grade Clan before spending any Lumens on Cursed Techniques

Your Clan provides passive stat multipliers that affect damage, cooldowns, and survivability across all content. Locking in a high-grade Clan first ensures every subsequent resource investment — Lumens on techniques, Yen on skill upgrades — is built on a strong foundation. Use the Clan Bag to store up to three Clan rolls for free so strong pulls are never accidentally overwritten while rerolling.

03
Dump 90–95% of Skill Points into Offense early — survivability can wait

Opening the menu and assigning nearly all early Skill Points into the Offense tree dramatically accelerates quest completion and enemy clearing speed. A high-damage build reduces time spent per encounter, which compounds into significantly faster XP and Yen accumulation over the course of a session. Defensive points become more meaningful once you are pushing high-difficulty content — they add little value during the early and mid-game grind.

04
Master the parry system immediately — it is the single most important combat mechanic in the game

Jujutsu Zero uses a timing-based parry system where a circle indicator closes in as an enemy attacks. Pressing Block just as the circle nearly closes performs a perfect parry, negating incoming damage entirely and dealing bonus damage to the enemy. Players who master parry timing spend significantly less time healing and can take on higher-level enemies earlier. Blocking without proper timing still reduces damage but produces chip damage and none of the counter-damage benefits.

05
Unlock every Teleport Totem you pass — fast travel access compounds in value over every session

Teleport points in Jujutsu Zero must be physically discovered and activated before they can be used for fast travel. Making a habit of pressing F near every totem encountered during normal exploration costs almost no time per instance but permanently reduces travel time for every future session. Quest NPCs are spread across the map, and unlocking totems near each one eliminates the need to run back on foot repeatedly throughout the game.

06
Check the Discord immediately after every update — new codes consistently drop with each patch

Jujutsu Zero releases codes alongside updates, milestone events, and bug fix patches — active codes like TRADING, 150KLIKES, and WEEKENDBOOST all followed specific in-game events. Joining the Studio Resonance Discord and checking announcements within the first hour of any update notification is the fastest way to claim codes before they expire. This release pattern makes Discord the most reliable source for upcoming code drops in the game.
