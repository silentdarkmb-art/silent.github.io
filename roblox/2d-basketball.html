How to Redeem Codes

  1. Join the MmiiGames Roblox Group first — some codes require group membership to redeem.
  2. Launch 2D Basketball on Roblox and wait for the main screen to load.
  3. Click the Gift icon at the bottom of the main screen to open the Rewards menu.
  4. Click the CODES tab at the top of the Rewards menu, then type or paste a working code into the grey text box and press REDEEM.

🏀 About the Game

About 2D Basketball🏀

Developed by MmiiGames • Roblox 2D Sports Game

2D Basketball is a side-scrolling basketball game on Roblox created by MmiiGames. Players compete head-to-head using precise timing and skill to shoot, dribble, and outmaneuver opponents in fast-paced 2D matches. The game features multiple maps and game modes — including ranked matches and free play — and rewards winners with Cash and XP used to unlock new basketballs, abilities, and cosmetics. There are no pay-to-win mechanics; every advantage is earned through gameplay.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Has Expired

2D Basketball codes are tied to milestones and can expire without notice. If the game returns an expired message, the code is no longer valid — check BLOXBURST for a current working list.

👥

Not in MmiiGames Group

Most 2D Basketball codes require you to be a member of the MmiiGames Roblox group before they can be redeemed. Join the group first, then try entering the code again.

🔡

Wrong Capitalization

All codes are case-sensitive. A single incorrect letter or mixed capitalization will cause the redemption to fail. Always copy and paste directly from BLOXBURST rather than typing manually.

🔄

Already Redeemed

Each code can only be claimed once per account. If you have already redeemed the code on your current Roblox account, the game will show an "already redeemed" message with no reward given.

🔧

Server Not Updated

New codes sometimes fail on older game servers. Exit 2D Basketball completely and rejoin to land in a fresh server running the latest build where the code will be recognized.

🖊️

Extra Space in Code

An accidental space before or after the code will trigger an invalid error even if the code itself is correct. Check both ends of the text field before pressing Redeem to avoid this.

⭐ Pro Tips

Beginner Tips for 2D Basketball🏀

Score more points and spend your Cash wisely from the start
01
Join the MmiiGames group before redeeming codes

Most active codes require group membership to work. Joining the official MmiiGames Roblox group is free and takes under a minute — do it before launching the game to avoid redemption failures.

02
Master the timing of your single jump button

Every action in 2D Basketball runs off one button. Learning exactly when to jump for a shot versus a block is the core skill gap between new players and experienced ones — practice in free play mode first.

03
Spend Cash on abilities before cosmetics

Abilities directly affect your performance in matches. Save your code-earned Cash for functional upgrades before spending on decorative basketballs or spin effects that don't change gameplay.

04
Use free play to learn each map layout

Each 2D Basketball map has different hoop heights and court sizes that change shot angles. Spending time in free play on unfamiliar maps before ranked matches gives you a meaningful advantage.

05
Like and favorite the game for milestone codes

MmiiGames releases codes when the game hits like and member milestones. Every like you leave brings the next free code drop closer for everyone — and costs you nothing.

06
Rejoin servers if a new code isn't working

Freshly released codes sometimes fail on older servers that haven't updated yet. If a code returns invalid right after release, exit the game and rejoin — a fresh server usually resolves this immediately.
