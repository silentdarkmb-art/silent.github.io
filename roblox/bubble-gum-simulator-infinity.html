🫧 About the Game

About Bubble Gum Simulator INFINITY

Developed by Rumble Studios • Roblox Bubble Clicker Simulator

Bubble Gum Simulator INFINITY is a clicker and simulator game on Roblox developed by Rumble Studios. Players blow bubble gum to increase its size, launch themselves into the sky, and discover floating islands and hidden secrets above the clouds. Hatching Eggs produces rare Pets with unique stat multipliers that boost how high and far you can blow — the more powerful your pet team, the more ground you cover per click. The game currently features the Spring Garden Event, where players pick Petals from flowers to spend at seasonal shops, hatch new Spring Eggs, and earn Spring Fountain Pass rewards. Codes in BGSI are not case-sensitive, making them easier to redeem than most Roblox games. Rumble Studios releases codes on their Twitter/X account (@RumbleStudiosRB) and in the Rumble Studios Discord server alongside major updates and milestone events.

🫧 Gameplay

Click to blow bubble gum, sell it for Coins, and reinvest in better gums and Eggs. Hatching Eggs gives you Pets that passively increase your blowing multiplier. Reach new cloud layers, unlock Sky Islands, and discover event-exclusive content. The Spring Garden Event adds Petal collection, seasonal Eggs, and limited-time shops to the core loop.

🎁 Code Drops

Rumble Studios releases codes on their Twitter/X page (@RumbleStudiosRB) and in the Rumble Studios Discord server. New codes tend to arrive with major game updates and seasonal events. Codes are not case-sensitive — upper or lower case both work — but extra spaces will still cause redemption failures.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
🚫

Extra Space in Code

BGSI codes are not case-sensitive, so capitalisation is not an issue — but accidental spaces before or after the code will cause an "Invalid Code" error even if everything else is correct. Always copy and paste directly from BLOXBURST and check that no trailing spaces were added during the paste.

⏰

Code Has Expired

BGSI codes expire without advance notice. The code whoops moved to a "Check" status on Roblox Den — a conflict flag — and has been moved to the expired section here per BLOXBURST's policy. Redeem every code the moment you find it rather than saving it for later.

📋

Conflict Between Sources

Some codes show as active on one site and expired or unconfirmed on another. BLOXBURST cross-checks Roblox Den, Try Hard Guides, Pocket Tactics, PCGamesN, and Sportskeeda before listing — any code flagged as "Check" or expired on any major tracker is immediately moved to our expired section rather than risking your attempt on an unreliable code.

🔄

Already Redeemed

Each BGSI code can only be claimed once per Roblox account. If the game displays an already-redeemed message, that reward was successfully collected earlier on your account. With 19 active codes available simultaneously, keeping a simple personal list of what you have already claimed saves repeated attempts.

🔧

Server Not Updated

Fresh codes released alongside a new game update can fail on older game servers still running the previous build. Close BGSI completely and rejoin — landing on a newly launched server running the current version almost always allows the code to register successfully on the next attempt.

📦

Reward Went to Inventory

Successful code redemptions in BGSI can drop rewards either directly into your currency counter or into your inventory. For Mystery Boxes, open the Items button at the bottom-right of the screen, click the Items tab, and find your boxes under the Powerups section — they may not appear in your main view automatically after redeeming.
