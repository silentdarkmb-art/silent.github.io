✨ About the Game

About Farm a Fish

Developed by Tetra Games • Fish farming tycoon on Roblox, formerly known as Fishies

Farm a Fish is a relaxing aquatic tycoon game on Roblox developed by Tetra Games, previously known as Fishies. Players start with a basic pond, place baits to attract fish, and sell their catches for Coins. Those Coins fund upgrades — better bait, stronger gear, and egg purchases that hatch into pets. Pets accelerate fish capture rates and provide passive income bonuses that scale with the pond's size and upgrade tier. Fish can be mutated into rarer versions that sell for significantly more Coins, and the pond itself expands as players invest in new sections and unlock premium fish species. The game follows the Grow a Garden style of incremental tycoon progression, making it easy to pick up but deeply engaging once the mutation and pet systems come into play.

🐟 Gameplay

Players deploy bait in their pond to attract fish, which are automatically collected and sold for Coins. Upgrading bait types improves the rarity and value of fish spawns, while gear crafting enhances collection efficiency across the pond. Pets hatched from purchased eggs provide unique passive bonuses — some increase catch speed while others boost the Coin multiplier on every sale. The goal is to expand the pond into multiple connected sections, each stocked with increasingly rare and valuable mutated fish that generate exponentially larger Coin payouts per collection cycle.

🎁 Code Drops

Tetra Games releases codes when Farm a Fish crosses player count milestones and during special in-game events. The current active codes follow a milestone naming pattern tied to the game's concurrent player and visit counts. All active codes are case-sensitive, and the two newer codes use uppercase-only formatting while the Wilco code uses mixed case. Codes are announced through the official Discord server in the game-updates channel, and the Tetra Games Roblox group page serves as a secondary announcement channel for milestone celebrations.

Why Some Codes Don't Work

Common issues & how to fix them fast
⏰

Code Expired

Farm a Fish codes expire without advance notice, typically when the next milestone is reached or a new update replaces the previous code batch. The game's milestone-based code pattern means each new code makes the previous tier more likely to expire soon after. BLOXBURST moves any code confirmed expired on any verified source to the expired section immediately — including codes flagged on even one additional trusted reference, per our conflict resolution policy for all Roblox code pages.

🔡

Case-Sensitive Input Error

Farm a Fish codes are fully case-sensitive — current active codes include a mix of all-uppercase, all-numeric, and mixed-case formats that must be entered exactly as shown. Entering a code in the wrong case triggers an invalid code error even if every character is otherwise correct. Copy and paste directly from BLOXBURST using the Copy button on each card to eliminate this risk entirely. Also check for any accidental spaces before or after the pasted code in the entry text box.

🔁

Already Redeemed

Each Farm a Fish code is single-use per Roblox account. If the game indicates the code has already been claimed, the rewards were added to your account in a previous session. With only four active codes currently available, tracking redeemed ones is straightforward — a "code already redeemed" error should not be confused with an expired or invalid code error, as the reward was successfully claimed in an earlier session rather than the code being broken.

🔧

Old Server After an Update

Codes released alongside a new update can fail on servers still running the previous game build. If a freshly confirmed code does not register on first attempt, exit Farm a Fish completely and rejoin to land on a server running the current version. This resolves build-mismatch errors quickly and is particularly relevant immediately after major milestone updates when servers gradually roll over to the new build while some instances continue running the previous version for up to an hour.

📋

Can't Find the Code Entry Field

The code redemption area in Farm a Fish is inside the Store window, which opens when you click the blue Shopping Basket icon on the left side of the screen. The code entry field is located at the very bottom of the Store window — it is not visible until you scroll all the way down past the shop items. Players who open the Store and see the item listings without scrolling will not find the code box. Scrolling the entire Store panel to the bottom reveals the Enter Code text box and Redeem button.

📋

Source Conflict — Code Moved to Expired

Any code confirmed as expired or flagged on any verified source is moved to the expired section on BLOXBURST immediately. Both expired codes on this page were confirmed inactive through cross-referencing — one was listed as expired by a source that updated more recently than those still showing it as active. If a code appears working on another tracking page but is listed as expired here, it has been confirmed inactive through a more recent verified cross-reference than the site still showing it active.

⭐ Pro Tips

Beginner Tips for Farm a Fish

Build your aquatic empire faster and unlock rarer fish from the start
01
Redeem all codes first — 75 Food Scoops and a free pet before your first cast

Two active codes combine for 75 Food Scoops and a third awards the Wilco Cat pet — all available the moment you open the game past the tutorial. Redeeming before your first collection cycle means your pet is already boosting fish capture rate and your Food Scoop inventory starts full. Using the Food Scoops during your first long session pushes Coin accumulation significantly faster than starting with an unfed pet on default performance.

02
Invest early Coins into bait upgrades before pond expansion

Expanding the pond adds more collection area, but the fish spawning in that area is only as valuable as the bait you have deployed. Upgrading bait quality first means every section of pond — existing and expanded — populates with higher-rarity fish that sell for more Coins per cycle. Players who expand their pond first and upgrade bait later end up with a large area producing low-value common fish, which produces slower Coin growth than a smaller pond fully stocked with quality bait.

03
Use the Golden Cookie during a long active session for maximum return

The Golden Cookie is a time-limited earnings multiplier — its boost applies to every fish sale during its active window. Using it during a short session or while stepping away from the game wastes the majority of the multiplier on idle time. Activate the Golden Cookie at the start of a dedicated long session where you can actively manage bait placement and pet feeding throughout the duration. Combining it with a Food Scoop activation at the same time produces the highest possible Coin yield per minute available in standard play.

04
Prioritize mutation upgrades once your base Coin income is stable

Fish mutations dramatically increase the sell value of common fish species — a mutated common fish can sell for several times more Coins than its base counterpart. Once your bait upgrades and pond expansion have established a reliable Coin income baseline, shifting investment toward mutation-related gear and crafting recipes is the fastest way to increase per-cycle Coin yield. Mutation upgrades compound with bait quality, meaning the combination produces earnings significantly beyond what either upgrade path delivers independently.

05
Hatch eggs strategically — don't buy multiple at the same time

Egg purchases in Farm a Fish use a randomized hatch system that can produce common pets or rare ones depending on the egg tier. Buying multiple eggs back-to-back before evaluating the pets you already have leads to inventory overcrowding and forces difficult decisions about which pets to keep or discard. Purchasing one egg, using the pet for a few sessions to assess its performance, and then deciding whether a better replacement is worth the next egg's Coin cost produces more efficient pet management than bulk purchasing early.

06
Join the Discord to stay ahead of the next milestone code

Every Farm a Fish code follows a player and visit milestone pattern — and the Discord game-updates channel posts new codes the moment those thresholds are crossed, typically before any external tracking page updates their list. Being in the Discord with notifications enabled means you see milestone codes immediately after they drop rather than hours later when other sources catch up. This is particularly important because Farm a Fish codes do not carry long active windows after new milestone codes replace them.
