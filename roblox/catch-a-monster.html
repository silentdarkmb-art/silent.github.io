How to Redeem Codes

  1. Launch Catch a Monster on Roblox and wait for the game to fully load.
  2. Click the gift box icon in the top-right corner of the screen.
  3. Type or paste your code into the Gift Code field — codes are case-sensitive.
  4. Click Redeem to instantly collect your free eggs, potions, rifts, or other rewards.
💬 If the code doesn't work, feel free to let us know in the comments so we can update the list!
🐾 About the Game

About Catch a Monster

Developed by LDS II • Roblox Monster Catching RPG

Catch a Monster is a Roblox monster-catching RPG developed by LDS II. Players battle wild creatures across an open world, capture them to fill out their Monsterdex, hatch rare eggs for powerful companions, and fuse monsters into stronger forms. Coins and XP fuel progression, and codes regularly provide potions, eggs, rifts, and event items to speed up the grind.

🎁 Rewards

What Do Codes Give You?

Free rewards deposited directly to your account on redemption
🥚

Eggs

Eggs are among the most valuable code rewards in Catch a Monster. Active codes currently award Sunforge eggs, Twilight Tree eggs, and Valentine eggs — each hatchable into a companion that joins your active roster. Higher-rarity egg types give a chance at monsters that are difficult or impossible to obtain through normal wild encounters.

Top Reward
🌀

Rifts

Rifts open access to special encounter zones where stronger and rarer monsters spawn. Active codes award Spirit Grove Rift IIIs and Valentine Rifts. Rifts are especially useful mid-game when normal map zones no longer offer enough challenge or drops to advance your Monsterdex efficiently.

Zone Access
⭐

XP & Coin Potions

XP Potions accelerate monster leveling, while Coin Potions boost currency earned during battles. Active codes award three Small XP Potions and three Small Coin Potions each — useful for pushing a key monster to its next evolution threshold or building up funds for a major egg purchase without grinding the same zone repeatedly.

Progress Boosts
🎁

Gear Chests

Gear Chests and Gilded Gear Chests contain materials and items used for upgrades and evolutions. Active codes award both standard and gilded versions — gilded chests contain higher-rarity contents. These become increasingly valuable as late-game evolutions require specific resources that drop infrequently through normal play.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues & how to fix them fast
🎁

Gift Box Not Visible

The code input in Catch a Monster is accessed through the gift box icon in the top-right corner of the screen. If the icon is not visible, wait for the game to fully load after joining — the UI sometimes takes a few extra seconds to appear on initial login or after a server transfer.

🔡

Case-Sensitive Typo

Catch a Monster codes are case-sensitive. Several active codes start with a capital letter — entering them fully lowercase or fully uppercase will cause the redemption to fail. Copy and paste directly from BLOXBURST to avoid any input error, especially with codes that mix upper and lowercase characters.

🔄

Already Redeemed

Each code is one-time use per Roblox account. If the game shows a message indicating the code has already been used, the egg, potion, or rift from that code was successfully collected at a prior point — it cannot be claimed a second time on the same account.

📋

Conflict Between Sources

Some codes appear active on one tracker but expired on another. BLOXBURST cross-checks multiple major sources before listing any code as active — if a code is expired or unconfirmed on any source, it goes to the expired section immediately, protecting you from wasted redemption attempts on codes that may no longer function.

🔧

Server Not Updated

New codes released alongside a game update can fail on servers still running the prior build. Leaving Catch a Monster and rejoining places you on a fresh server with the latest version — this resolves most cases where a newly released code rejects on the first attempt.

⏰

Code Has Expired

Catch a Monster codes expire without advance notice or countdown timers. A code listed as active on an outdated tracker can fail the moment you try it. BLOXBURST flags and moves any code that appears in a source's expired section immediately — always use the verified active list at the top of this page before attempting a redemption.

⭐ Pro Tips

Beginner Tips for Catch a Monster

Build a stronger squad and get the most out of every code
01
Redeem all active codes before your first session

All ten confirmed active codes award eggs, potions, rifts, or gear chests immediately on redemption. Claiming everything before playing gives you hatching material, XP boosts, and gear to start with — a stronger opening squad makes the early map zones significantly easier to clear and capture from.

02
Hatch egg rewards from codes before spending Coins

Eggs from codes cost nothing and can yield high-rarity companions that would otherwise require significant Coin investment to obtain. Hatch all code eggs first to assess your starting roster before deciding where to spend in-game currency — a lucky hatch can change your entire early strategy.

03
Save XP Potions for monsters close to evolving

Small XP Potions from codes are most effective when applied to a monster that is within range of its next evolution threshold. Using them on a monster far from evolving wastes most of the potential gain — check each monster's current XP progress before deciding where to apply the boost.

04
Use Rifts to access harder zones earlier than normal

Rifts from codes let you enter encounter zones with stronger monsters before you would normally qualify by level progression. This can significantly accelerate Monsterdex completion if you enter with a high-rank bodyguard companion to handle the battles while you focus on capturing new species.

05
Fuse duplicates to increase rank instead of releasing them

Duplicate monsters caught in the wild or hatched from eggs can be fused to raise the rank of the base version. Higher-rank monsters deal more damage and survive longer in battle. Storing duplicates rather than discarding them gives you fusion material that directly improves your strongest teammates.

06
Enable Discord notifications for the codes channel

New codes appear in the Lightning Dragon Studios Discord server before reaching any external tracker. Enabling notifications specifically for the codes channel means you see every new drop within minutes of release — giving you the best chance of redeeming before an unannounced expiry removes it.
