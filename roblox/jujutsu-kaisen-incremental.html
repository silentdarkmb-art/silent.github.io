⚡ About the Game

About Jujutsu Kaisen Incremental

Developed by Real Mouse Productions • Roblox Jujutsu Kaisen Incremental RPG

Jujutsu Kaisen Incremental is a Jujutsu Kaisen-inspired incremental RPG developed by Real Mouse Productions on Roblox. Players grow from a weak sorcerer into an unstoppable one by training hard, fighting terrifying cursed spirits, unlocking powerful cursed techniques, and completing story missions adapted from the anime. Boss encounters reward cursed tools and rare drops that shape your character's power trajectory, while clan bonuses provide passive multipliers that stack across the entire progression system. Rolls and Rerolls from codes give new players an immediate edge — skipping the slowest phases of early technique and clan assignment grinding entirely.

⚠️ Troubleshoot

Why Some Codes Don't Work

Common issues and how to fix them fast
🔡

Case-Sensitive Input

All Jujutsu Kaisen Incremental codes are fully case-sensitive. Entering any character incorrectly — including capitalisation — produces an immediate rejection. Copy and paste directly from BLOXBURST to eliminate input errors entirely. On mobile, autocorrect can silently alter the first character of a pasted code — verify the text field content after pasting before pressing Redeem.

⏰

Code Has Expired

Jujutsu Kaisen Incremental codes can expire without advance notice. BLOXBURST cross-checks multiple sources before updating the active list — any code showing expired or conflicting status is moved immediately. If a code does not appear in the active list here, it has been flagged and will not work.

👥

Not in the Roblox Group

Jujutsu Kaisen Incremental requires all players to be members of the Real Mouse Productions Roblox Group before any code can be redeemed. Attempting to redeem without group membership will result in an immediate failure regardless of whether the code is valid. Join the group first, then relaunch the game and attempt the redemption again — this resolves the vast majority of first-time redemption failures.

🔧

Old Server After Update

Codes released with a new Jujutsu Kaisen Incremental update can fail on servers still running the previous build. If a newly announced code returns invalid on the first attempt — particularly within the first hour or two of a patch — exit the game entirely and rejoin to land on a fresh server running the current version. This resolves almost all build-related redemption failures immediately.

🚫

Extra Space in the Code Field

Copying a code can include a hidden leading or trailing space that triggers an invalid response even when all visible characters are correct. After pasting, click at the very start and end of the code field to check for extra spaces before pressing Redeem. On mobile, clipboard paste behaviour varies between apps and spaces are easily introduced without any visible indicator.

🔄

Already Redeemed

Each Jujutsu Kaisen Incremental code is single-use per Roblox account. If the game returns an already-redeemed message, the Rolls or Rerolls were added to your account in a previous session. Players returning after a gap may have claimed codes they no longer remember redeeming — checking the active list against memory before attempting codes prevents repeated failed attempts.

⭐ Pro Tips

Beginner Tips for Jujutsu Kaisen Incremental

Unlock powerful techniques, defeat cursed spirits, and progress through story arcs faster from day one
01
Join the Real Mouse Productions Roblox Group before anything else — it's required for codes

Before launching the game for the first time, join the Real Mouse Productions Roblox Group. Group membership is a hard requirement for code redemption — no code will activate without it. Joining takes seconds and immediately unlocks access to all 15 active codes, including THEJJKISITUATIONISCRAZY and CLANWARS which award 80 combined Rerolls before your first fight.

02
Redeem all codes before rolling for your first technique — stack free rolls first

After joining the group, redeem all active codes before spending any resources on technique rolls. The Rerolls from THEJJKISITUATIONISCRAZY and CLANWARS combined with the free rewards from other codes give you a significantly broader starting roll pool. Beginning your first technique roll session with this stockpile maximises your chance of landing a rare technique without grinding.

03
Prioritise story mission completion over grinding — bosses drop cursed tools that upgrade fast

Story mission bosses in Jujutsu Kaisen Incremental drop Cursed Tools that provide direct combat upgrades unavailable through grinding alone. Pushing story missions forward as quickly as possible — even with a suboptimal technique — yields boss tool drops that more than compensate for the technique gap. Grinding on earlier enemies while leaving story missions incomplete is the most common early-game progression mistake.

04
Use Rerolls in batches rather than one at a time to track results accurately

Rolling techniques one at a time makes it difficult to assess whether your current result is worth keeping before spending more Rerolls. Using several Rerolls in a short session and comparing results gives a clearer picture of what the current roll pool can offer at your progression stage. Keeping a mental note of the best result seen in each batch session helps set a realistic benchmark for when to stop rolling and invest in the current technique.

05
Participate in Raids as soon as they unlock — raid rewards accelerate progression significantly

Raids in Jujutsu Kaisen Incremental reward drops and progression resources that are unavailable through solo play. The RAIDSUPDATE code was released specifically to celebrate this content — meaning the developers consider it a core part of progression. Joining raids as soon as the content unlocks provides a second income stream of drops and rewards that compounds directly into faster story mission completion and technique upgrade opportunities.

06
Check the Discord announcements channel immediately after every update for new codes

Real Mouse Productions releases new codes through the Discord server and Roblox group page, consistently tied to major updates and visit milestones. The JJK3D, 1MVISITS, and RAIDSUPDATE codes are direct examples of this pattern. Checking the announcements channel within the first hour of any update notification is the fastest way to claim codes before other players redeem them and before any expiry window closes.
