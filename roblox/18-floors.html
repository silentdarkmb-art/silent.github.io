  1. Launch 18 Floors on Roblox and wait for the main lobby to load completely.
  2. Locate the Profile button (person icon) on the left side of your screen and click it to open your profile panel.

About 18 Floors

Co-op Horror Survival by Synthic Studios · Roblox

18 Floors is a tense cooperative survival experience developed by Synthic Studios on Roblox, where players team up with friends to navigate increasingly dangerous maze-like floors while evading iconic horror monsters. The game blends exploration, resource management, and tactical combat into a high-stakes loop where every decision — from route planning to weapon selection — can mean the difference between escape and elimination. With each ascending floor, enemies grow stronger, loot becomes rarer, and the pressure to coordinate with your squad intensifies.

At its foundation, 18 Floors rewards communication and adaptability. Finding better guns on higher floors isn't just about raw firepower — it's about matching your loadout to your team's strategy and the specific threats you face. Credits, the game's core currency, unlock new classes and cosmetic skins through the Daily Shop, allowing players to personalize their experience without compromising the skill-based core gameplay. Codes provide one of the fastest ways to earn Credits, giving both new and veteran players a meaningful boost without disrupting the game's carefully balanced progression.

Synthic Studios actively engages with the 18 Floors community through regular updates and milestone celebrations. Codes are frequently released to mark achievements like member counts, favorite milestones, or seasonal events — giving players extra resources to experiment with new classes or collect limited-time cosmetics. For the freshest codes, bookmark this page or join the official Synthic Studios Discord for real-time announcements straight from the developers.

Whether you're a casual player looking for spooky fun with friends or a hardcore grinder aiming to conquer all 18 floors, this game offers scalable challenge and rewarding teamwork mechanics. ⚠️ Troubleshoot

Why Some 18 Floors Codes Don't Work

Six common reasons and exactly how to fix each one
🔡

Wrong Letter Case

18 Floors' code system is fully case-sensitive. A single uppercase letter entered as lowercase (or vice versa) will trigger an invalid error even if the rest of the code is correct. Always replicate capitalization exactly as shown, or copy-paste directly from our verified list to eliminate any typo risk entirely.

🔣

Extra Spaces or Characters

Accidentally copying a leading space, trailing space, or stray punctuation alongside the code will cause it to fail. The input field only accepts the exact alphanumeric string. When in doubt, paste your code into a plain text editor first to strip any hidden formatting, then copy it cleanly into the game's code box.

⏰

Code Has Expired

Many 18 Floors codes are tied to limited-time campaigns — update launches, holiday events, or player count celebrations. Once that window closes, the code deactivates automatically with no warning. If a correctly formatted code still fails, it has likely expired. Check back on this page for freshly verified replacements.

🔄

Server Out of Sync

Brand new codes sometimes take a few minutes to propagate across all active game servers. If you're trying a code right after it was announced and it's failing, the server you're on may be running an older build. Leave the game completely, wait a couple of minutes, then rejoin — you'll likely land on a fresh server where the code is recognized.

🔑

Already Redeemed

Each code in 18 Floors can only be claimed once per account. If you've already used a code in a previous session, attempting to enter it again will return an error. Keep a personal log of codes you've already claimed so you don't waste time re-entering them — or simply skip codes marked with dates older than your last redemption session.

👥

Group Membership Required

Occasionally, Synthic Studios releases exclusive codes that are only redeemable by members of their official Roblox Group. If a code works for others but not for you, check whether group membership is a listed requirement. Joining is free — visit the Synthic Studios group page and hit Join to unlock access.

Pro Tips for 18 Floors — Advanced Strategies

Go beyond basic survival and dominate the floors with these game-specific tactics
01
Redeem All Active Codes Before Spending Credits

Before you invest any earned Credits into unlocking classes or skins, claim every active code on this page first. Free Credits from codes add to your pool without costing you any earned progress. This small habit at the start of each session can meaningfully accelerate your loadout experimentation, especially after major updates when multiple new codes drop simultaneously.

02
Assign Clear Roles Before Each Floor

Not all team compositions are equal. Rather than everyone doing the same tasks, assign complementary roles — one player scouts ahead, another covers rear defense, and a third focuses on looting. A well-coordinated trio with clear responsibilities will consistently outlast groups relying on individual skill alone.

03
Learn Monster Spawn Patterns Per Floor

Each floor in 18 Floors has unique monster behaviors and spawn locations. Spend your early runs mapping these patterns rather than rushing for loot. Knowing where threats emerge lets your team position defensively and avoid ambushes that wipe out hard-earned progress.

04
Save Credits for Meta-Relevant Classes

While cosmetic skins are tempting, unlocking classes that complement your team's strategy provides compounding value across every run. Hold your Credits — whether earned or from codes — for classes that fill gaps in your squad's composition rather than duplicating existing roles.

05
Practice Retreat Routes Before Pushing Deep

Knowing how to escape is often more valuable than knowing how to advance. Before committing to a high-risk floor section, identify at least two viable retreat paths. This preparation turns potential wipe scenarios into manageable repositioning opportunities, preserving your team's momentum.

06
Check for Codes Every Time the Game Updates

Synthic Studios consistently releases new codes alongside version patches and milestone announcements. Make it a habit to check BLOXBURST or the official Discord server immediately after any patch notification. Update-day codes tend to be the most generous, often awarding multiple Credits at once — and they frequently expire within days of release.
